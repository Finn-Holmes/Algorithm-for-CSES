## 题目描述

有 \(n\) 个密室，每个密室 \(i\) 都会将探险者传送到密室 \(a_i\)。

对于每次询问，给定起点 \(x\) 和传送次数 \(y\)，求连续传送 \(y\) 次后所在的密室。

## 输入

第一行两个整数 `n, m`，表示密室数量和询问数量。

第二行包含 `n` 个整数，其中 `a[i]` 表示从密室 `i` 会传送到密室 `a[i]`。

接下来 `m` 行，每行两个整数 `x, y`，表示起点和传送次数。

## 输出

对于每次询问，输出最终所在的密室编号。

## 样例输入

```text
4 3
2 3 4 2
1 2
2 3
1 9
```

## 样例输出

```text
3
2
4
```

## 提示或数据范围

- 1 ≤ n, m ≤ 100000
- 1 ≤ a[i] ≤ n
- 1 ≤ x ≤ n
- 0 ≤ y ≤ 10^9

## 题解

如果按照每次传送逐步模拟，单次询问的复杂度为 `O(y)`，无法通过。

使用倍增预处理：

`up[j][i]` 表示从密室 `i` 出发，连续传送 \(2^j\) 次后到达的密室。

初始状态为：

$$
up[0][i]=a_i
$$

状态转移为：

$$
up[j][i]=up[j-1][up[j-1][i]]
$$

因为传送 \(2^j\) 次，可以拆成两段 \(2^{j-1}\) 次传送。

处理询问时，将 `y` 按照二进制拆分。若 `y` 的第 `j` 位为 1，就从当前密室传送 \(2^j\) 次：

```C++
x=up[j][x];
```

由于 `y ≤ 10^9`，预处理 31 层即可。

## 复杂度分析

预处理时间复杂度：`O(n log y)`。

每次询问时间复杂度：`O(log y)`。

空间复杂度：`O(n log y)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

const int LOG=31;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin>>n>>m;

    vector<vector<int>> up(LOG,vector<int>(n+1));

    for(int i=1;i<=n;i++){
        cin>>up[0][i];
    }

    for(int j=1;j<LOG;j++){
        for(int i=1;i<=n;i++){
            up[j][i]=up[j-1][up[j-1][i]];
        }
    }

    while(m--){
        int x;
        long long y;
        cin>>x>>y;

        for(int j=0;j<LOG;j++){
            if((y>>j)&1){
                x=up[j][x];
            }
        }

        cout<<x<<'\n';
    }

    return 0;
}
```
