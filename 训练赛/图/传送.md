## 题目描述

有 `n` 个小镇和 `m` 条双向传送通道，每经过一条通道需要花费 `1` 分钟。

对于一条通道 `(u,v)`：

- 如果 `u` 不为 `0`，表示它连接小镇 `u` 和小镇 `v`；
- 如果 `u=0`，表示它的一端是小镇 `v`，另一端暂时没有确定。

现在有 `n` 个询问。对于第 `x` 个询问，将所有未确定的端点都设为小镇 `x`，求从小镇 `1` 到小镇 `n` 的最短时间。

如果无法到达，输出 `-1`。

## 输入

第一行包含两个整数 `n,m`，表示小镇数量和传送通道数量。

接下来 `m` 行，每行包含两个整数 `u,v`，表示一条传送通道。

## 输出

输出一行 `n` 个整数，第 `x` 个整数表示将所有未确定端点设为 `x` 时，从小镇 `1` 到小镇 `n` 的最短时间。

## 样例输入

```text
3 2
0 2
1 2
```

## 样例输出

```text
-1 -1 2
```

## 数据范围

- 2 ≤ n ≤ 3 × 10^5
- 1 ≤ m ≤ 3 × 10^5
- 0 ≤ u < v ≤ n
- 图中没有重边

## 题解

先只考虑所有已经确定的边，并在这个图上进行两次 BFS：

- `d1[u]` 表示从小镇 `1` 到小镇 `u` 的最短距离；
- `dn[u]` 表示从小镇 `u` 到小镇 `n` 的最短距离。

将所有不确定边 `(0,v)` 中的节点 `v` 保存到 `special` 中，并计算：

```text
best1 = min(d1[v])
bestn = min(dn[v])
```

其中 `v` 属于 `special`。

对于询问节点 `x`，所有不确定边都会变成 `x-v`。由于这些新增边都与 `x` 相连，一条最短路最多只需要使用两条新增边。

因此只需要考虑四种情况：

```text
不使用新增边：
d1[n]

先到x，再使用一条新增边：
d1[x]+1+bestn

先到特殊节点，再通过新增边到x：
best1+1+dn[x]

使用两条新增边经过x：
best1+2+bestn
```

取四种情况的最小值即可。

## 复杂度分析

两次 BFS 的时间复杂度为 `O(n+m)`，之后每个询问只需要常数时间。

总时间复杂度为 `O(n+m)`。

空间复杂度为 `O(n+m)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

const int INF=1e9;

vector<vector<int>> graph;

vector<int> bfs(int head){
    vector<int> dis(graph.size(),INF);
    queue<int> q;

    dis[head]=0;
    q.push(head);

    while(!q.empty()){
        int u=q.front();
        q.pop();

        for(int v:graph[u]){
            if(dis[v]==INF){
                dis[v]=dis[u]+1;
                q.push(v);
            }
        }
    }

    return dis;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin>>n>>m;

    graph.resize(n+1);

    vector<int> special;
    special.reserve(m);

    for(int i=0;i<m;i++){
        int u,v;
        cin>>u>>v;

        if(u==0){
            special.push_back(v);
        }else{
            graph[u].push_back(v);
            graph[v].push_back(u);
        }
    }

    vector<int> d1=bfs(1);
    vector<int> dn=bfs(n);

    int best1=INF;
    int bestn=INF;

    for(int v:special){
        best1=min(best1,d1[v]);
        bestn=min(bestn,dn[v]);
    }

    for(int x=1;x<=n;x++){
        int ans=d1[n];

        if(d1[x]!=INF&&bestn!=INF){
            ans=min(ans,d1[x]+1+bestn);
        }

        if(best1!=INF&&dn[x]!=INF){
            ans=min(ans,best1+1+dn[x]);
        }

        if(best1!=INF&&bestn!=INF){
            ans=min(ans,best1+2+bestn);
        }

        if(ans==INF){
            cout<<-1;
        }else{
            cout<<ans;
        }

        if(x<n){
            cout<<' ';
        }
    }

    return 0;
}
```
