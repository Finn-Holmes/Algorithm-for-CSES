## 题目描述

在所有满足下列条件的排列 `P` 中，找出字典序最小的排列。

`P` 是 `1,2,...,N` 的一个排列。

对于每个限制 `(Ai,Bi)`，要求 `Ai` 在排列中出现在 `Bi` 之前。

如果不存在满足条件的排列，输出 `-1`。

## 输入

第一行包含两个整数 `N,M`，分别表示排列的长度和限制条件的数量。

接下来 `M` 行，每行包含两个整数 `Ai,Bi`，表示 `Ai` 必须出现在 `Bi` 之前。

## 输出

如果存在满足所有限制条件的排列，输出字典序最小的排列。

如果不存在，输出 `-1`。

## 样例输入

```text
4 3
2 1
3 4
2 4
```

## 样例输出

```text
2 1 3 4
```

## 数据范围

- 2 ≤ N ≤ 200000
- 1 ≤ M ≤ 200000
- 1 ≤ Ai,Bi ≤ N
- Ai ≠ Bi

## 题解

每个限制 `Ai` 在 `Bi` 之前，可以看作一条从 `Ai` 指向 `Bi` 的有向边，因此问题就是求字典序最小的拓扑序。

在拓扑排序板子的基础上，将普通队列改为小根堆，每次选择当前所有入度为 `0` 的节点中编号最小的节点，即可得到字典序最小的拓扑序。

如果最终得到的节点数量小于 `N`，说明图中存在环，输出 `-1`。

## 复杂度分析

时间复杂度为 `O((N+M)log N)`，空间复杂度为 `O(N+M)`。



## code

```C++
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n,m;
    cin>>n>>m;

    vector<int> du(n+1,0);
    vector<vector<int>> e(n+1,vector<int>());

    for(int i=0;i<m;i++){
        int u,v;
        cin>>u>>v;

        e[u].push_back(v);
        du[v]++;
    }

    priority_queue<int,vector<int>,greater<int>> q;
    vector<int> ans;

    for(int i=1;i<=n;i++){
        if(du[i]==0){
            q.push(i);
        }
    }

    while(!q.empty()){
        int x=q.top();
        q.pop();

        ans.push_back(x);

        for(int y:e[x]){
            du[y]--;

            if(du[y]==0){
                q.push(y);
            }
        }
    }

    if(ans.size()==n){
        for(int i=0;i<n;i++){
            cout<<ans[i]<<" ";
        }
    }else{
        cout<<-1;
    }

    return 0;
}
```
