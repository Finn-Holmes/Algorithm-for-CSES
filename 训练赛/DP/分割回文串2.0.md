## 题目描述

给定一个由小写字母组成的字符串 `s` 和一个整数 `k`。

首先可以将 `s` 中的部分字符修改为其他小写英文字母，然后需要将 `s` 分割成 `k` 个非空且互不相交的子串，并保证每个子串都是回文串。

求完成分割所需修改的最少字符数量。

## 输入

给定一个字符串 `s` 和一个整数 `k`。

## 输出

返回将 `s` 分割成 `k` 个回文子串所需修改的最少字符数量。

## 样例输入

```text
s = "abc", k = 2
```

## 样例输出

```text
1
```

可以将字符串分割成 `"ab"` 和 `"c"`，修改 `"ab"` 中的一个字符即可使其成为回文串。

## 数据范围

- 1 ≤ k ≤ s.length ≤ 100
- `s` 只包含小写英文字母

## 题解

首先预处理每个子串修改成回文串所需的最少修改次数，然后进行分割 DP。

### 预处理回文修改次数

令 `hui[l][r]` 表示将子串 `s[l...r]` 修改成回文串所需的最少修改次数。

如果 `s[l]` 和 `s[r]` 相同，就不需要修改首尾字符；否则需要修改其中一个字符。因此：

$$
hui[l][r]=hui[l+1][r-1]+[s[l]\ne s[r]]
$$

其中：

- 长度为 `1` 的子串修改次数为 `0`；
- 长度为 `2` 的子串根据两个字符是否相同，修改次数为 `0` 或 `1`。

因为计算 `hui[l][r]` 需要使用 `hui[l+1][r-1]`，所以左端点 `l` 要从大到小枚举。

### 分割 DP

令 `dp[i][r]` 表示将前缀 `s[0...r]` 分割成 `i` 个非空回文子串所需的最少修改次数。

当只分割成一个子串时：

$$
dp[1][r]=hui[0][r]
$$

对于 `i≥2`，枚举最后一个子串的左端点。假设最后一个子串是 `s[l+1...r]`，那么前面的 `s[0...l]` 需要分割成 `i-1` 个回文子串：

$$
dp[i][r]=\min_{i-2\le l\le r-1}\left(dp[i-1][l]+hui[l+1][r]\right)
$$

`l` 至少为 `i-2`，这样前面的 `l+1` 个字符才足够分割成 `i-1` 个非空子串。

最终答案为 `dp[k][n-1]`。

## 复杂度分析

预处理 `hui` 的时间复杂度为 `O(n²)`。

分割 DP 的时间复杂度为 `O(k × n²)`。

总时间复杂度为 `O(k × n²)`。

空间复杂度为 `O(n² + k × n)`。

## code

```C++
class Solution {
public:
    int palindromePartition(string s, int k) {
        int n=s.size();

        vector<vector<int>> hui(
            n,
            vector<int>(n,INT_MAX)
        );

        // 预处理每个子串修改成回文串的最少次数
        for(int l=n-1;l>=0;l--){
            for(int r=l;r<n;r++){
                if(l==r){
                    hui[l][r]=0;
                }else if(l+1==r){
                    if(s[l]==s[r]){
                        hui[l][r]=0;
                    }else{
                        hui[l][r]=1;
                    }
                }else{
                    hui[l][r]=hui[l+1][r-1];

                    if(s[l]!=s[r]){
                        hui[l][r]++;
                    }
                }
            }
        }

        vector<vector<int>> dp(
            k+1,
            vector<int>(n+1,INT_MAX)
        );

        // 将前缀整体作为一个回文子串
        for(int r=0;r<n;r++){
            dp[1][r]=hui[0][r];
        }

        // 枚举分割的子串数量
        for(int i=2;i<=k;i++){
            // i个非空子串至少需要i个字符
            for(int r=i-1;r<n;r++){
                // 最后一个子串为s[l+1...r]
                for(int l=i-2;l<r;l++){
                    dp[i][r]=min(
                        dp[i][r],
                        dp[i-1][l]+hui[l+1][r]
                    );
                }
            }
        }

        return dp[k][n-1];
    }
};
```
