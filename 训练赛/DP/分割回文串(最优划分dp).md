## 题目描述

给定一个字符串 `s`，将其分割成若干个子串，使每个子串都是回文串。

求满足要求的最少分割次数。

## 输入

给定一个只包含小写英文字母的字符串 `s`。

## 输出

返回将 `s` 分割成若干个回文子串所需的最少分割次数。

## 样例输入

```text
s = "aab"
```

## 样例输出

```text
1
```

只需要分割一次，即可得到两个回文子串：

```text
["aa","b"]
```

## 数据范围

- 1 ≤ s.length ≤ 2000
- `s` 只包含小写英文字母

## 题解

首先预处理字符串中所有区间是否为回文串，然后使用动态规划计算最少分割次数。

### 预处理回文区间

令 `is[l][r]` 表示子串 `s[l...r]` 是否为回文串。

如果首尾字符相同，并且内部子串也是回文串，那么当前区间就是回文串：

$$
is[l][r]=(s[l]=s[r])\land is[l+1][r-1]
$$

计算 `is[l][r]` 时需要使用 `is[l+1][r-1]`，因此左端点 `l` 要从大到小枚举。

代码将整个数组初始化为 `true`。这样：

- 长度为 `1` 的区间默认为回文串；
- 对于长度为 `2` 的区间，内部区间为空，也可以视为回文串。

### 计算最少分割次数

令 `dp[r]` 表示将前缀 `s[0...r]` 分割成回文子串所需的最少分割次数。

如果 `s[0...r]` 本身就是回文串，则不需要分割：

$$
dp[r]=0
$$

否则枚举最后一个回文子串的左端点 `l`。如果 `s[l...r]` 是回文串，就在 `l-1` 和 `l` 之间进行一次分割：

$$
dp[r]=\min(dp[r],dp[l-1]+1)
$$

最终答案为 `dp[n-1]`。

## 复杂度分析

预处理回文区间和计算最少分割次数都需要枚举所有区间。

时间复杂度为 `O(n²)`。

空间复杂度为 `O(n²)`。

## code

```C++
class Solution {
public:
    int minCut(string s) {
        int n=s.size();

        vector<vector<bool>> is(
            n,
            vector<bool>(n,true)
        );

        // 预处理每个子串是否为回文串
        for(int l=n-2;l>=0;l--){
            for(int r=l+1;r<n;r++){
                if(s[l]==s[r]&&is[l+1][r-1]){
                    is[l][r]=true;
                }else{
                    is[l][r]=false;
                }
            }
        }

        // dp[r]表示前缀s[0...r]的最少分割次数
        vector<int> dp(n);

        for(int r=0;r<n;r++){
            // 整个前缀本身就是回文串
            if(is[0][r]){
                continue;
            }

            int res=INT_MAX;

            // 枚举最后一个回文子串的左端点
            for(int l=1;l<=r;l++){
                if(is[l][r]){
                    res=min(res,dp[l-1]+1);
                }
            }

            dp[r]=res;
        }

        return dp[n-1];
    }
};
```
