# 移除所有载有违禁货物车厢所需的最少时间

## 题目描述

给定一个二进制字符串 `s`，表示一列火车车厢：

- `s[i]=='0'` 表示第 `i` 节车厢不含违禁货物；
- `s[i]=='1'` 表示第 `i` 节车厢含有违禁货物。

可以不限次数执行以下操作：

1. 从左端移除一节车厢，花费 1；
2. 从右端移除一节车厢，花费 1；
3. 从任意位置移除一节车厢，花费 2。

求移除所有含有违禁货物车厢所需的最少时间。

## 输入

输入一个二进制字符串 `s`。

## 输出

返回移除所有含有违禁货物车厢需要的最少时间。

## 样例输入

```text
1100101
```

## 样例输出

```text
5
```

## 数据范围

- 1 ≤ s.length ≤ 200000
- `s[i]` 为 `0` 或 `1`

## 题解

## 方法一：前缀和与公式拆分

假设保留一个区间 `[i,j]`，那么：

- `[0,i)` 中的车厢全部从左端删除，花费 `i`；
- `(j,n)` 中的车厢全部从右端删除，花费 `n-j-1`；
- `[i,j]` 中所有的 `1` 从中间删除，每个花费 2。

设 `pre[i]` 表示 `s[0...i]` 中 `1` 的数量，并规定 `pre[-1]=0`，那么总花费为：

$$
i+(n-j-1)+2\times(pre[j]-pre[i-1])
$$

将与 `i`、`j` 有关的部分拆开：

$$
(i-2\times pre[i-1])+(2\times pre[j]-j)+(n-1)
$$

枚举右端点 `j` 时，维护：

$$
prebest=\min_{0\le i\le j}(i-2\times pre[i-1])
$$

当前右端点对应的最小花费为：

$$
prebest+2\times pre[j]-j+n-1
$$

实现时，`presum` 在加入 `s[j]` 之前表示 `pre[j-1]`，所以应该先使用它更新 `prebest`，再加入当前字符并计算答案。

还需要考虑删除整列火车的方案，花费为 `n`。

### 复杂度分析

时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

### code

```C++
class Solution {
public:
    int minimumTime(string s) {
        int n=s.size();

        int presum=0;
        int prebest=0;
        int ans=INT_MAX;

        for(int j=0;j<n;j++){
            // 此时presum表示pre[j-1]
            prebest=min(prebest,j-2*presum);

            presum+=s[j]-'0';

            ans=min(ans,prebest+2*presum-j);
        }

        return min(n,ans+n-1);
    }
};
```

## 方法二：前后缀分解 DP

设 `suf[i]` 表示清除后缀 `s[i...n-1]` 中所有 `1` 的最小时间。

如果 `s[i]=='0'`，当前车厢不需要删除：

$$
suf[i]=suf[i+1]
$$

如果 `s[i]=='1'`，有两种选择：

1. 单独删除当前车厢，再处理后面的车厢，花费 `suf[i+1]+2`；
2. 从右端删除整个后缀，花费 `n-i`。

因此：

$$
suf[i]=\min(suf[i+1]+2,n-i)
$$

然后从左向右枚举分割位置。

使用变量 `pre` 表示清除前缀 `s[0...i]` 中所有 `1` 的最小时间。

当 `s[i]=='1'` 时：

- 单独删除当前车厢，花费 `pre+2`；
- 从左端删除整个前缀，花费 `i+1`。

所以：

$$
pre=\min(pre+2,i+1)
$$

在位置 `i` 后面进行分割，前缀使用 `pre` 处理，后缀使用 `suf[i+1]` 处理，总花费为：

$$
pre+suf[i+1]
$$

由于遇到 `0` 时，前缀与后缀的最小代价都不会发生有效变化，所以只需要在 `s[i]=='1'` 时更新答案。

### 复杂度分析

时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

### code

```C++
class Solution {
public:
    int minimumTime(string s) {
        int n=s.size();

        vector<int> suf(n+1,0);

        for(int i=n-1;i>=0;i--){
            if(s[i]=='0'){
                suf[i]=suf[i+1];
            }else{
                suf[i]=min(suf[i+1]+2,n-i);
            }
        }

        int ans=suf[0];
        int pre=0;

        for(int i=0;i<n;i++){
            if(s[i]=='1'){
                pre=min(pre+2,i+1);
                ans=min(ans,pre+suf[i+1]);
            }
        }

        return ans;
    }
};
```

## 两种方法对比

- 方法一把总花费公式拆成与左右端点分别有关的部分，通过维护前缀最小值完成优化，空间复杂度为 `O(1)`。
- 方法二分别计算前缀和后缀的最优清除代价，再枚举分割位置，状态含义更加直观，但需要 `O(n)` 的额外空间。
