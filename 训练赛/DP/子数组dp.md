# 统计乘积余数对应的子数组数量

## 题目描述

给定一个由正整数组成的数组 `nums` 和一个正整数 `k`。

可以执行一次操作：移除任意不重叠的前缀和后缀，并保证剩余数组非空。

对于每个 `x`，统计有多少种操作可以使剩余元素的乘积除以 `k` 的余数等于 `x`。

返回一个长度为 `k` 的数组 `result`，其中 `result[x]` 表示乘积余数为 `x` 的操作数量。

## 输入

输入一个正整数数组 `nums` 和一个正整数 `k`。

## 输出

返回一个长度为 `k` 的数组，其中第 `x` 个位置表示乘积除以 `k` 的余数为 `x` 的操作数量。

## 样例输入

```text
nums = [1,2,3,4,5], k = 3
```

## 样例输出

```text
[9,2,4]
```

## 数据范围

- 1 ≤ nums[i] ≤ 1000000000
- 1 ≤ nums.length ≤ 100000
- 1 ≤ k ≤ 5

## 题解

移除一个前缀和一个后缀后，剩余部分一定是一个非空连续子数组。

反过来，数组中的每一个非空连续子数组，也都可以通过移除它左边的前缀和右边的后缀得到。

因此，题目可以转化为：

> 统计所有非空连续子数组的乘积模 `k` 后分别等于多少。

设：

```C++
dp[i][r]
```

表示以 `nums[i-1]` 结尾，并且元素乘积除以 `k` 的余数为 `r` 的子数组数量。

处理 `nums[i]` 时，令：

```C++
v=nums[i]%k;
```

首先，单独选择 `nums[i]` 可以组成一个新的子数组：

```C++
dp[i+1][v]=1;
```

然后，将所有以 `nums[i-1]` 结尾的子数组向右扩展一个元素。

如果原来的乘积余数为 `r`，加入 `nums[i]` 后，新的余数为：

$$
(r\times v)\bmod k
$$

因此转移为：

```C++
dp[i+1][r*v%k]+=dp[i][r];
```

计算完所有以 `nums[i]` 结尾的子数组后，将它们加入最终答案：

```C++
ans[r]+=dp[i+1][r];
```

最终 `ans[r]` 就是乘积除以 `k` 的余数为 `r` 的所有非空连续子数组数量。

答案最大可能达到：

$$
\frac{n(n+1)}2
$$

所以答案数组需要使用 `long long`。

## 复杂度分析

时间复杂度为 `O(nk)`。

空间复杂度为 `O(nk)`。

## code

```C++
class Solution {
public:
    vector<long long> resultArray(vector<int>& nums, int k) {
        int n=nums.size();

        vector<long long> ans(k);
        vector<vector<long long>> dp(
            n+1,vector<long long>(k,0)
        );

        for(int i=0;i<n;i++){
            int v=nums[i]%k;

            // 单独选择nums[i]
            dp[i+1][v]=1;

            // 将以前一个位置结尾的子数组向右扩展
            for(int r=0;r<k;r++){
                dp[i+1][r*v%k]+=dp[i][r];
            }

            // 统计所有以nums[i]结尾的子数组
            for(int r=0;r<k;r++){
                ans[r]+=dp[i+1][r];
            }
        }

        return ans;
    }
};
```
