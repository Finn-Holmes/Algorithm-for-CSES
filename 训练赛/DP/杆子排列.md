## 题目描述

有高度分别为 1, 2, ..., n 的杆子排列成一排。

从左侧或右侧观察时，较矮的杆子会被前面较高的杆子遮挡。

给定 n、l 和 r，求有多少种杆子排列满足：

- 从左侧可以看到 l 根杆子；
- 从右侧可以看到 r 根杆子。

## 输入

第一行输入一个整数 T，表示测试用例数量。

接下来 T 行，每行输入三个整数 n、l 和 r。

## 输出

对于每组测试数据，输出一行一个整数，表示满足条件的排列数量。

## 样例输入

```text
4
4 1 2
4 1 1
5 2 4
20 2 1
```

## 样例输出

```text
2
0
4
6402373705728000
```

## 数据范围

- 1 ≤ l, r ≤ n
- n ≤ 20

## 题解

设 `dp[n][l][r]` 表示 n 根杆子中，从左边能看到 l 根、从右边能看到 r 根的排列数量。

考虑在一个包含 `n-1` 根杆子的排列中加入最矮的杆子。

最矮的杆子有三种放置情况：

1. 放在最左边，它会从左侧被看到，因此左侧可见数量增加 1；
2. 放在最右边，它会从右侧被看到，因此右侧可见数量增加 1；
3. 放在中间，它一定会被其他杆子挡住，不会影响两侧的可见数量。中间共有 `n-2` 个位置。

因此状态转移为：

$$
dp[n][l][r]=dp[n-1][l-1][r]+dp[n-1][l][r-1]+(n-2)\times dp[n-1][l][r]
$$

初始只有一根杆子时，从左右两侧都能看到它：

$$
dp[1][1][1]=1
$$

由于 n 最大只有 20，可以预处理所有状态，每次询问直接输出对应的 `dp[n][l][r]`。

## 复杂度分析

预处理时间复杂度为 `O(20³)`，每次询问的时间复杂度为 `O(1)`。

空间复杂度为 `O(20³)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

long long dp[21][21][21];

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    dp[1][1][1]=1;

    for(int n=2;n<=20;n++){
        for(int l=1;l<=n;l++){
            for(int r=1;r<=n;r++){
                dp[n][l][r]+=dp[n-1][l-1][r];
                dp[n][l][r]+=dp[n-1][l][r-1];
                dp[n][l][r]+=1LL*(n-2)*dp[n-1][l][r];
            }
        }
    }

    int T;
    cin>>T;

    while(T--){
        int n,l,r;
        cin>>n>>l>>r;
        cout<<dp[n][l][r]<<'\n';
    }

    return 0;
}
```
