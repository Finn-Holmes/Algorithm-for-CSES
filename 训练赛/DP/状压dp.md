## 题目描述

给定整数 `n`，使用 `1～n` 构造一个排列 `perm`。

如果对于每个位置 `i`，至少满足以下一个条件，则称该排列为优美排列：

- `perm[i]` 能被 `i` 整除；
- `i` 能被 `perm[i]` 整除。

请返回优美排列的数量。

## 样例

### 样例 1

```text
输入：n = 2
输出：2
```

两个优美排列分别为：

```text
[1,2]
[2,1]
```

### 样例 2

```text
输入：n = 1
输出：1
```

## 数据范围

- 1 ≤ n ≤ 15

## 题解

由于 `n` 最大只有 `15`，可以使用状压 DP。

用一个 `n` 位二进制数 `s` 表示已经使用的数字集合，其中第 `j-1` 位为 `1`，表示数字 `j` 已经被使用。

定义 `dp[s]` 表示使用集合 `s` 中的数字，填入排列前 `popcount(s)` 个位置的方案数。

初始化：

```C++
dp[0]=1;
```

对于状态 `s`，令：

```C++
i=popcount(s);
```

表示当前需要填写第 `i` 个位置。

枚举放在位置 `i` 的数字 `j`。如果 `j` 在集合 `s` 中，并且满足：

```C++
i%j==0||j%i==0
```

那么删除数字 `j` 后，剩余数字组成的状态为：

```C++
s^(1<<(j-1))
```

因此进行转移：

```C++
dp[s]+=dp[s^(1<<(j-1))];
```

最终 `(1<<n)-1` 表示所有数字都被使用，答案为：

```C++
dp[(1<<n)-1]
```

## 复杂度分析

一共有 `2^n` 个状态，每个状态枚举 `n` 个数字。

时间复杂度为 `O(n·2^n)`，空间复杂度为 `O(2^n)`。

## code

```C++
class Solution {
public:
    int countArrangement(int n) {
        vector<int> dp(1<<n);
        dp[0]=1;

        for(int s=1;s<1<<n;s++){
            int i=popcount((unsigned)s);

            for(int j=1;j<=n;j++){
                if((s>>(j-1)&1)&&(i%j==0||j%i==0)){
                    dp[s]+=dp[s^(1<<(j-1))];
                }
            }
        }

        return dp[(1<<n)-1];
    }
};
```
