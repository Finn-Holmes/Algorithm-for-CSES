# 字符串的总引力

## 题目描述

字符串的引力定义为字符串中不同字符的数量。

给定一个只包含小写英文字母的字符串 `s`，求 `s` 的所有子字符串的引力之和。

子字符串是字符串中一段连续的字符序列。

## 输入

输入一个只包含小写英文字母的字符串 `s`。

## 输出

返回 `s` 的所有子字符串的引力之和。

## 样例输入

```text
abbca
```

## 样例输出

```text
28
```

## 数据范围

- 1 ≤ s.length ≤ 100000
- `s` 只包含小写英文字母

## 题解

可以使用贡献法，计算每个位置的字符对最终答案产生了多少贡献。

对于位置 `i`，设：

```C++
last[s[i]]
```

表示字符 `s[i]` 上一次出现的位置。如果此前没有出现过，则为 `-1`。

为了让位置 `i` 成为某个子字符串中字符 `s[i]` 的第一次出现，子字符串的左端点可以选择：

$$
last[s[i]]+1\le l\le i
$$

一共有：

$$
i-last[s[i]]
$$

种选择。

子字符串的右端点只需要包含位置 `i`，因此可以选择：

$$
i\le r\le n-1
$$

一共有：

$$
n-i
$$

种选择。

所以位置 `i` 对答案的贡献为：

$$
(i-last[s[i]])\times(n-i)
$$

对于任意一个子字符串中的每一种不同字符，我们只在该字符第一次出现在这个子字符串时计算贡献，因此不会重复计数。

每次处理完位置 `i` 后，更新该字符最后一次出现的位置：

```C++
last[s[i]-'a']=i;
```

由于答案可能很大，需要使用 `long long`。

## 复杂度分析

时间复杂度为 `O(n)`。

由于字符集大小固定为 26，空间复杂度为 `O(1)`。

## code

```C++
class Solution {
public:
    long long appealSum(string s) {
        int n=s.size();

        vector<int> last(26,-1);
        long long ans=0;

        for(int i=0;i<n;i++){
            int c=s[i]-'a';

            ans+=(long long)(i-last[c])*(n-i);

            last[c]=i;
        }

        return ans;
    }
};
```
