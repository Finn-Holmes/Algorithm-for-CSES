## 题目描述

给定一个整数数组 `arr`，选择一个非空连续子数组，并可以决定是否从中删除一个元素。

删除后，子数组中必须至少剩下一个元素。

求经过至多一次删除后，可以得到的最大子数组元素和。

## 输入

输入一个整数数组 `arr`。

## 输出

返回经过至多一次删除后，能够得到的最大子数组和。

## 样例输入

```text
arr = [1,-2,0,3]
```

## 样例输出

```text
4
```

## 题解

使用动态规划。

定义：

- `dp[i][0]`：选择以 `arr[i]` 结尾的子数组，并且没有删除元素时的最大和；
- `dp[i][1]`：选择一个延伸到 `arr[i]` 的子数组，并且已经删除一个元素后能够得到的最大和。

### 没有删除元素

对于 `dp[i][0]`，有两种选择：

1. 将 `arr[i]` 接在前面的子数组后面；
2. 从 `arr[i]` 重新开始一个子数组。

转移方程为：

$$
dp[i][0]=\max(dp[i-1][0]+arr[i],arr[i])
$$

### 已经删除一个元素

对于 `dp[i][1]`，也有两种选择。

第一种是删除当前元素 `arr[i]`，那么结果直接继承前一个没有删除元素的状态：

$$
dp[i][1]=dp[i-1][0]
$$

第二种是保留当前元素，删除操作已经在前面完成：

$$
dp[i][1]=dp[i-1][1]+arr[i]
$$

因此完整转移为：

$$
dp[i][1]=\max(dp[i-1][0],dp[i-1][1]+arr[i])
$$

初始化：

```C++
dp[0][0]=arr[0];
dp[0][1]=0;
```

`dp[0][1]=0` 表示删除第一个元素后的临时状态，但不能单独作为答案，因为删除后子数组不能为空。

所以答案初始为：

```C++
ans=dp[0][0];
```

之后从 `i=1` 开始，使用两种状态更新答案。这样在数组全部为负数时，答案仍然会选择一个负数，而不会错误地返回 `0`。

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## code

```C++
class Solution {
public:
    int maximumSum(vector<int>& arr) {
        int n=arr.size();

        vector<vector<int>> dp(
            n,vector<int>(2)
        );

        dp[0][0]=arr[0];
        dp[0][1]=0;

        int ans=dp[0][0];

        for(int i=1;i<n;i++){
            // 不删除元素：接在前面，或者从当前元素重新开始
            dp[i][0]=max(
                dp[i-1][0]+arr[i],
                arr[i]
            );

            // 删除当前元素，或者删除操作已经在前面完成
            dp[i][1]=max(
                dp[i-1][0],
                dp[i-1][1]+arr[i]
            );

            ans=max({
                ans,
                dp[i][0],
                dp[i][1]
            });
        }

        return ans;
    }
};
```
