## 题目描述

给定一个字符串 `s`，每次操作可以在字符串的任意位置插入任意字符。

求至少需要插入多少个字符，才能使 `s` 变成回文串。

## 输入

输入一个仅由小写英文字母组成的字符串 `s`。

## 输出

返回将 `s` 变成回文串所需的最少插入次数。

## 样例输入

```text
s = "mbadm"
```

## 样例输出

```text
2
```

## 数据范围

- 1 <= s.length <= 500
- `s` 中的字符均为小写英文字母

## 题解

如果原字符串中存在一个长度为 `L` 的回文子序列，那么可以保留这个子序列中的字符，并为剩余字符分别插入对应的对称字符，从而构造出回文串。

为了使插入次数最少，应该保留尽可能多的字符，也就是求字符串的最长回文子序列。

设最长回文子序列的长度为 `L`，字符串长度为 `n`，则最少插入次数为：

$$
n-L
$$

定义 `dp[l][r]` 表示子串 `s[l...r]` 中最长回文子序列的长度。

当两端字符相同时，可以同时选择这两个字符：

$$
dp[l][r]=dp[l+1][r-1]+2
$$

当两端字符不同时，至少舍弃其中一端：

$$
dp[l][r]=\max(dp[l+1][r],dp[l][r-1])
$$

单个字符本身就是长度为 `1` 的回文子序列，因此：

$$
dp[i][i]=1
$$

最终最长回文子序列的长度为 `dp[0][n-1]`。

## 复杂度分析

时间复杂度为 `O(n²)`。

空间复杂度为 `O(n²)`。

## code

```C++
class Solution {
public:
    int minInsertions(string s) {
        int n=s.size();

        vector<vector<int>> dp(
            n+1,vector<int>(n+1,0)
        );

        for(int l=n-1;l>=0;l--){
            dp[l][l]=1;

            for(int r=l+1;r<n;r++){
                if(s[l]==s[r]){
                    dp[l][r]=dp[l+1][r-1]+2;
                }else{
                    dp[l][r]=max(
                        dp[l+1][r],
                        dp[l][r-1]
                    );
                }
            }
        }

        return n-dp[0][n-1];
    }
};
```
