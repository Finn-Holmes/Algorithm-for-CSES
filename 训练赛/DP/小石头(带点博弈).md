## 题目描述

开始时有 `N` 个石子，以及一个长度为 `K` 的序列：

```text
A1,A2,...,AK
```

Alice 和 Bob 轮流取石子，Alice 先手。

每次操作可以选择一个 `Ai`，取走 `Ai` 个石子。当无法继续取石子时游戏结束。

两人都会采用最优策略，使自己最终取走的石子数量尽可能多。求 Alice 最终能够取走多少个石子。

## 输入

第一行输入两个整数 `N,K`。

第二行输入 `K` 个整数 `A1,A2,...,AK`，表示每次可以取走的石子数量。

## 输出

输出一个整数，表示双方都采用最优策略时，Alice 最终取走的石子数量。

## 样例输入

```text
10 2
1 4
```

## 样例输出

```text
5
```

## 数据范围

- 1 <= N <= 10000
- 1 <= K <= 100
- 1 = A1 < A2 < ... < AK <= N

## 题解

定义：

`dp[x]` 表示当前轮到操作的人，面对剩余 `x` 个石子时，最终最多能够取走的石子数量。

假设当前选择取走 `num` 个石子，那么还剩下 `x-num` 个石子，并且接下来轮到对方操作。

根据定义，对方在剩余的 `x-num` 个石子中最多能够取走：

```text
dp[x-num]
```

因为 `A1=1`，所有石子最终一定会被取完。当前一共有 `x` 个石子，对方取走 `dp[x-num]` 个，因此当前玩家最终能够取走：

$$
x-dp[x-num]
$$

枚举当前可以取走的所有 `num`，状态转移为：

$$
dp[x]=\max_{num\le x}\left(x-dp[x-num]\right)
$$

从小到大计算 `dp[1],dp[2],...,dp[N]`，最终 `dp[N]` 就是 Alice 能够取走的最大石子数量。

## 复杂度分析

时间复杂度为 `O(NK)`。

空间复杂度为 `O(N)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,k;
    cin>>n>>k;

    vector<int> nums(k);

    for(int i=0;i<k;i++){
        cin>>nums[i];
    }

    vector<int> dp(n+1,0);

    for(int x=1;x<=n;x++){
        for(int num:nums){
            if(num>x){
                break;
            }

            dp[x]=max(dp[x],x-dp[x-num]);
        }
    }

    cout<<dp[n];

    return 0;
}
```
