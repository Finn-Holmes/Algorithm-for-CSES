## 题目描述

给定一个长度为 `n` 的整数数组 `nums`。

三段式子数组是一个连续子数组 `nums[l...r]`，并且存在下标 `l < p < q < r`，满足：

- `nums[l...p]` 严格递增；
- `nums[p...q]` 严格递减；
- `nums[q...r]` 严格递增。

求所有三段式子数组中的最大元素和。

## 输入

输入一个整数数组 `nums`。

## 输出

返回元素和最大的三段式子数组的元素和。

## 样例输入

```text
nums = [0,-2,-1,-3,0,2,-1]
```

## 样例输出

```text
-4
```

## 数据范围

- 4 ≤ n ≤ 100000
- -1000000000 ≤ nums[i] ≤ 1000000000
- 保证至少存在一个三段式子数组

## 题解

根据三段式子数组的三个变化阶段进行动态规划。

定义：

- `dp[i][1]`：以 `nums[i]` 结尾，目前处于第一段严格递增时的最大元素和；
- `dp[i][2]`：以 `nums[i]` 结尾，已经完成第一段递增，目前处于严格递减时的最大元素和；
- `dp[i][3]`：以 `nums[i]` 结尾，已经完成递增和递减，目前处于最后一段严格递增时的最大元素和。

所有状态必须至少包含一条对应方向的边，因此第一段递增只能从一对满足 `nums[i-1] < nums[i]` 的元素开始。

### 当前是上升关系

当 `nums[i-1] < nums[i]` 时，可以更新第一段递增：

$$
dp[i][1]=\max(dp[i-1][1],nums[i-1])+nums[i]
$$

其中：

- `dp[i-1][1]+nums[i]` 表示继续原来的第一段递增；
- `nums[i-1]+nums[i]` 表示从当前这两个元素重新开始。

同时可以更新最后一段递增：

$$
dp[i][3]=\max(dp[i-1][3],dp[i-1][2])+nums[i]
$$

其中：

- 从 `dp[i-1][3]` 转移表示继续最后一段递增；
- 从 `dp[i-1][2]` 转移表示结束递减阶段，开始最后一段递增。

### 当前是下降关系

当 `nums[i-1] > nums[i]` 时，可以更新递减阶段：

$$
dp[i][2]=\max(dp[i-1][2],dp[i-1][1])+nums[i]
$$

其中：

- 从 `dp[i-1][2]` 转移表示继续递减；
- 从 `dp[i-1][1]` 转移表示结束第一段递增，开始递减。

当相邻元素相等时，既不满足严格递增，也不满足严格递减，因此不能进行任何状态转移。

只有 `dp[i][3]` 表示三个阶段全部出现，所以使用它更新最终答案。

由于数组和可能达到很大的负数，所有状态和答案都必须使用 `long long`，无效状态初始化为 `LLONG_MIN/2`。

## 复杂度分析

- 时间复杂度：O(n)
- 空间复杂度：O(n)

## code

```C++
class Solution {
public:
    long long maxSumTrionic(vector<int>& nums) {
        long long ans=LLONG_MIN/2;
        int n=nums.size();

        vector<vector<long long>> dp(
            n+1,
            vector<long long>(4,LLONG_MIN/2)
        );

        for(int i=1;i<n;i++){
            if(nums[i-1]<nums[i]){
                dp[i][3]=max(
                    dp[i-1][3],
                    dp[i-1][2]
                )+nums[i];

                dp[i][1]=max(
                    dp[i-1][1],
                    (long long)nums[i-1]
                )+nums[i];

            }else if(nums[i-1]>nums[i]){
                dp[i][2]=max(
                    dp[i-1][2],
                    dp[i-1][1]
                )+nums[i];
            }

            ans=max(ans,dp[i][3]);
        }

        return ans;
    }
};
```
