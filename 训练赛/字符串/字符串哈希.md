## 题目描述

给定一个字符串 `s`，需要将它划分为若干个非空且互不重叠的连续子串：

```text
s=a1+a2+...+ad
```

如果这些子串按照整体来看构成回文，即：

```text
a1=ad
a2=a(d-1)
...
```

那么这种划分称为回文划分。

求最多可以将字符串划分成多少个块。

## 输入

第一行输入一个整数 `t`，表示测试用例数量。

接下来 `t` 行，每行输入一个只包含小写英文字母的字符串 `s`。

## 输出

对于每组测试数据，输出一个整数，表示最多能够划分出的块数。

## 样例输入

```text
4
bonobo
deleted
racecar
racecars
```

## 样例输出

```text
3
5
7
1
```

## 数据范围

- 1 ≤ t ≤ 10
- 1 ≤ n ≤ 1000000

其中 `n` 表示字符串的长度。

## 题解

为了让划分出的块数最多，每次应该寻找当前字符串最短的、相同的前缀和后缀。

找到后，它们可以分别作为最左边和最右边的两个块，答案加 `2`，然后继续处理剩余的中间部分。

如果最后只剩下中间的一段无法继续配对，则它自己作为一个块，答案加 `1`。

直接创建前缀和后缀字符串并比较，最坏时间复杂度为 `O(n²)`。由于字符串长度可以达到 `1000000`，因此使用滚动哈希进行判断。

将字符映射为数字：

```text
a → 1
b → 2
...
z → 26
```

左侧字符串按照正常顺序加入字符：

$$
leftHash=(leftHash\times BASE+x)\bmod MOD
$$

右侧从右向左扫描，因此新字符需要放在已有字符串前面：

$$
rightHash=(rightHash+y\times power)\bmod MOD
$$

其中 `power` 表示当前需要使用的 `BASE` 次幂。

例如两边的字符串都是 `"ab"`：

- 左边依次扫描 `a,b`，哈希值为 `1×BASE+2`；
- 右边依次扫描 `b,a`，哈希值为 `2+1×BASE`。

两者结果相同。

为了降低不同字符串产生相同哈希值的概率，代码使用两个不同的模数进行双哈希。只有两组哈希值都相同，才认为当前前缀和后缀相同。

每找到一对相同的前后缀后，需要将哈希值和 `power` 重置，开始处理下一组。

## 复杂度分析

每个字符只会被扫描一次。

- 时间复杂度：O(n)
- 额外空间复杂度：O(1)

## code

```C++
#include <bits/stdc++.h>
using namespace std;

const long long MOD1=1e9+7;
const long long MOD2=1e9+9;
const long long BASE=131;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin>>t;

    while(t--){
        string s;
        cin>>s;

        int n=s.size();
        int l=0,r=n-1;
        int ans=0;

        bool is=false;

        long long left1=0,right1=0,power1=1;
        long long left2=0,right2=0,power2=1;

        while(l<=r){
            int x=s[l]-'a'+1;
            int y=s[r]-'a'+1;

            left1=(left1*BASE+x)%MOD1;
            left2=(left2*BASE+x)%MOD2;

            right1=(right1+y*power1)%MOD1;
            right2=(right2+y*power2)%MOD2;

            is=true;

            if(left1==right1&&left2==right2){
                if(l==r){
                    ans++;
                }else{
                    ans+=2;
                }

                left1=0;
                left2=0;
                right1=0;
                right2=0;

                power1=1;
                power2=1;

                is=false;
            }else{
                power1=power1*BASE%MOD1;
                power2=power2*BASE%MOD2;
            }

            l++;
            r--;
        }

        // 中间还有一段没有找到对应的前后缀
        if(is){
            ans++;
        }

        cout<<ans<<'\n';
    }

    return 0;
}
```
