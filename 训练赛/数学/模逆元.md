# 模意义下的逆元总结

## 逆元的定义

在模 `m` 意义下，如果存在整数 `x` 满足：

$$
ax\equiv1\pmod m
$$

那么称 `x` 是 `a` 在模 `m` 意义下的逆元，记作：

$$
x\equiv a^{-1}\pmod m
$$

逆元存在的充要条件是：

$$
\gcd(a,m)=1
$$

例如，`3` 在模 `7` 意义下的逆元是 `5`，因为：

$$
3\times5=15\equiv1\pmod7
$$

模意义下不能直接进行普通除法：

```C++
a/b%MOD
```

如果 `b` 的逆元存在，应写成：

```C++
a*inverse(b)%MOD
```

---

## 方法一：费马小定理求逆元

### 适用条件

- 模数 `MOD` 是质数；
- `a%MOD!=0`；
- 只需求少量逆元。

根据费马小定理：

$$
a^{MOD-1}\equiv1\pmod {MOD}
$$

因此：

$$
a^{-1}\equiv a^{MOD-2}\pmod {MOD}
$$

使用快速幂计算即可。

```C++
#include <bits/stdc++.h>
using namespace std;

long long quick_pow(long long a,long long b,long long mod){
    long long res=1;

    while(b){
        if(b&1){
            res=res*a%mod;
        }

        a=a*a%mod;
        b>>=1;
    }

    return res;
}

long long get_inverse(long long a,long long mod){
    return quick_pow(a,mod-2,mod);
}
```

使用方法：

```C++
const long long MOD=1000000007;

long long inverse=get_inverse(a,MOD);
```

模意义下计算除法：

```C++
long long answer=x*get_inverse(y,MOD)%MOD;
```

必须保证：

```C++
y%MOD!=0
```

### 复杂度

每次求逆元的时间复杂度为 `O(log MOD)`，空间复杂度为 `O(1)`。

---

## 方法二：扩展欧几里得求逆元

### 适用条件

- 模数不一定是质数；
- `gcd(a,mod)==1`；
- 只需求少量逆元。

扩展欧几里得可以求出整数 `x,y`，使：

$$
ax+mod\times y=\gcd(a,mod)
$$

如果 `a` 和 `mod` 互质，就有：

$$
ax+mod\times y=1
$$

对 `mod` 取模后得到：

$$
ax\equiv1\pmod {mod}
$$

因此 `x` 就是 `a` 的逆元。

```C++
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a,long long b,long long& x,long long& y){
    if(b==0){
        x=1;
        y=0;
        return a;
    }

    long long x1,y1;
    long long g=exgcd(b,a%b,x1,y1);

    x=y1;
    y=x1-a/b*y1;

    return g;
}

long long get_inverse(long long a,long long mod){
    long long x,y;
    long long g=exgcd(a,mod,x,y);

    if(g!=1){
        return -1;
    }

    return (x%mod+mod)%mod;
}
```

使用方法：

```C++
long long inverse=get_inverse(a,mod);

if(inverse==-1){
    cout<<"逆元不存在";
}else{
    cout<<inverse;
}
```

例如：

```C++
get_inverse(3,8)
```

结果为 `3`，因为：

$$
3\times3\equiv1\pmod8
$$

而 `2` 在模 `8` 意义下没有逆元，因为：

$$
\gcd(2,8)=2
$$

### 复杂度

每次求逆元的时间复杂度为 `O(log mod)`，递归空间复杂度为 `O(log mod)`。

---

## 方法三：线性预处理逆元

### 适用条件

- 模数 `MOD` 是质数；
- 需要求 `1～n` 的所有逆元；
- `n<MOD`。

递推公式为：

$$
inverse[i]=(MOD-\lfloor MOD/i\rfloor)\times inverse[MOD\bmod i]\bmod MOD
$$

代码如下：

```C++
#include <bits/stdc++.h>
using namespace std;

const long long MOD=1000000007;

int main(){
    int n;
    cin>>n;

    vector<long long> inverse(n+1);

    inverse[1]=1;

    for(int i=2;i<=n;i++){
        inverse[i]=
            (MOD-MOD/i)*inverse[MOD%i]%MOD;
    }

    for(int i=1;i<=n;i++){
        cout<<inverse[i]<<' ';
    }

    return 0;
}
```

与对每个数分别使用快速幂相比，线性预处理可以将复杂度从 `O(n log MOD)` 降低到 `O(n)`。

### 复杂度

时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

## 方法四：阶乘逆元

### 适用场景

组合数问题经常需要计算：

$$
\binom nr=\frac{n!}{r!(n-r)!}
$$

模意义下不能直接除法，因此需要预处理：

```C++
factorial[i]
inverse_factorial[i]
```

其中：

```C++
factorial[i]
```

表示 `i!`。

```C++
inverse_factorial[i]
```

表示 `i!` 的逆元。

通常要求：

- `MOD` 是质数；
- `n<MOD`。

### 预处理方法

先正序计算所有阶乘：

```C++
factorial[i]=factorial[i-1]*i%MOD;
```

使用快速幂计算 `n!` 的逆元：

```C++
inverse_factorial[n]=quick_pow(factorial[n],MOD-2,MOD);
```

然后倒序计算其他阶乘逆元：

```C++
inverse_factorial[i-1]=inverse_factorial[i]*i%MOD;
```

完整模板：

```C++
#include <bits/stdc++.h>
using namespace std;

const long long MOD=1000000007;

vector<long long> factorial;
vector<long long> inverse_factorial;

long long quick_pow(long long a,long long b,long long mod){
    long long res=1;

    while(b){
        if(b&1){
            res=res*a%mod;
        }

        a=a*a%mod;
        b>>=1;
    }

    return res;
}

void init_factorial(int n){
    factorial.resize(n+1);
    inverse_factorial.resize(n+1);

    factorial[0]=1;

    for(int i=1;i<=n;i++){
        factorial[i]=factorial[i-1]*i%MOD;
    }

    inverse_factorial[n]=
        quick_pow(factorial[n],MOD-2,MOD);

    for(int i=n;i>=1;i--){
        inverse_factorial[i-1]=
            inverse_factorial[i]*i%MOD;
    }
}

long long combination(int n,int r){
    if(r<0||r>n){
        return 0;
    }

    return factorial[n]
        *inverse_factorial[r]%MOD
        *inverse_factorial[n-r]%MOD;
}

int main(){
    int n,r;
    cin>>n>>r;

    init_factorial(n);

    cout<<combination(n,r);

    return 0;
}
```

### 复杂度

预处理时间复杂度为 `O(n+log MOD)`，每次计算组合数的时间复杂度为 `O(1)`。

空间复杂度为 `O(n)`。

---

## 负数取模的处理

扩展欧几里得求出的逆元可能是负数，例如：

```text
-2
```

应将其转换到 `[0,mod-1]` 范围：

```C++
x=(x%mod+mod)%mod;
```

普通负数取模时也可以这样处理：

```C++
value=(value%mod+mod)%mod;
```

---

## 方法选择

| 使用场景 | 推荐方法 | 复杂度 |
| --- | --- | --- |
| 模数是质数，只求少量逆元 | 费马小定理与快速幂 | `O(log MOD)` |
| 模数不一定是质数 | 扩展欧几里得 | `O(log MOD)` |
| 求 `1～n` 的所有逆元 | 线性预处理 | `O(n)` |
| 多次计算组合数 | 阶乘与阶乘逆元 | 预处理 `O(n+log MOD)`，查询 `O(1)` |

## 注意事项

1. 逆元存在的充要条件是 `gcd(a,mod)==1`。
2. 当 `MOD` 是质数时，只要 `a%MOD!=0`，逆元就存在。
3. 费马小定理只能直接用于质数模数。
4. 线性逆元通常要求 `MOD` 是质数且 `n<MOD`。
5. 预处理阶乘逆元时通常要求 `n<MOD`，否则 `n!` 可能在模 `MOD` 下等于 `0`。
6. 模意义下的除法需要转化为乘逆元。
