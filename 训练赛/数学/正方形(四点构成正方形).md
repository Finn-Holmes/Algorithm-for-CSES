## 题目描述

在地图上散落着 `n` 个车轮，小 J 想用它们造一辆车。

一辆车需要四个车轮，并且四个车轮所在的位置构成一个正方形，车轮不能移动。

请计算有多少种造车方案。如果两个方案所使用的车轮不完全相同，则认为它们是不同的方案。坐标相同的两个车轮也视为不同车轮。

## 输入

第一行包含一个整数 `n`，表示车轮数量。

接下来 `n` 行，每行包含两个整数 `x,y`，表示一个车轮位于 `(x,y)`。

## 输出

输出一个整数，表示造车方案数。

## 样例输入

```text
9
0 0
1 0
2 0
0 2
1 2
2 2
0 1
1 1
2 1
```

## 样例输出

```text
6
```

## 数据范围

- 对于 30% 的数据：n ≤ 30
- 对于 100% 的数据：1 ≤ n ≤ 1000，|x|, |y| < 20000

## 题解

枚举两个不同的坐标，将它们看作正方形的一条对角线。

设对角线的两个端点为 `A(x1,y1)` 和 `C(x2,y2)`。对角线中点为：

$$
\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2}\right)
$$

将向量 `(x2-x1,y2-y1)` 旋转 90 度，再以对角线中点为中心，可以得到另外两个顶点：

$$
B\left(
\frac{x_1+x_2+y_1-y_2}{2},
\frac{y_1+y_2+x_2-x_1}{2}
\right)
$$

$$
D\left(
\frac{x_1+x_2+y_2-y_1}{2},
\frac{y_1+y_2+x_1-x_2}{2}
\right)
$$

如果坐标的分子中存在奇数，说明另外两个顶点不是整数坐标；否则在 `map` 中查找这两个坐标是否存在。

使用 `cnt` 记录每个坐标上的车轮数量。找到一个正方形后，它产生的方案数为四个顶点上的车轮数量之积。

每个正方形有两条对角线，因此会被统计两次，最终答案需要除以 2。

## 复杂度分析

设不同坐标数量为 `p`，其中 `p ≤ n`。

时间复杂度为 `O(n² log n)`，空间复杂度为 `O(n)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    map<pair<int,int>,long long> cnt;
    for(int i=0;i<n;i++){
        int x,y;
        cin>>x>>y;
        cnt[{x,y}]++;
    }
    vector<pair<int,int>> a;
    for(auto it:cnt){
        a.push_back(it.first);
    }
    long long ans=0;
    for(int i=0;i<a.size();i++){
        for(int j=i+1;j<a.size();j++){
            int x1=a[i].first;
            int y1=a[i].second;
            int x2=a[j].first;
            int y2=a[j].second;
            int x3=x1+x2+y1-y2;
            int y3=y1+y2+x2-x1;
            int x4=x1+x2+y2-y1;
            int y4=y1+y2+x1-x2;
            if(x3&1||y3&1||x4&1||y4&1) continue;
            auto it1=cnt.find({x3/2,y3/2});
            auto it2=cnt.find({x4/2,y4/2});
            if(it1==cnt.end()||it2==cnt.end()) continue;
            ans+=it1->second*it2->second*cnt[{x1,y1}]*cnt[{x2,y2}];
        }
    }
    cout<<ans/2;
    return 0;
}
```
