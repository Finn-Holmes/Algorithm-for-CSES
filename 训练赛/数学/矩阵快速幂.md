## 题目描述

给定一个只包含小写字母的字符串 `S1`，需要构造一个长度为 `n` 的小写字母字符串 `S2`。

要求 `S1` 中出现过的所有相邻字母，都不能以相同顺序在 `S2` 中相邻出现。

求满足要求的字符串 `S2` 的数量，答案对 `1000000007` 取模。

## 输入

第一行包含一个正整数 `n`，表示字符串 `S2` 的长度。

第二行包含一个只由小写字母组成的字符串 `S1`。

## 输出

输出一个整数，表示合法字符串 `S2` 的数量，对 `1000000007` 取模。

## 样例输入

```text
2
ab
```

## 样例输出

```text
675
```

## 数据范围

- n ≤ 10^15
- S1 的长度不超过 100000
- S1 只包含小写英文字母

## 题解

`S2` 中每个字符的选择只与前一个字符有关，因此可以建立字母之间的转移矩阵。

定义 `trans[i][j]` 表示字母 `i` 后面能否接字母 `j`：

- 如果这个相邻组合在 `S1` 中出现过，则 `trans[i][j]=0`；
- 否则 `trans[i][j]=1`。

例如 `S1="ab"`，则：

```C++
trans['a'-'a']['b'-'a']=0;
```

其余转移均为 `1`。

长度为 `n` 的字符串包含 `n-1` 次相邻字符转移，因此需要计算：

$$
trans^{n-1}
$$

其中：

```C++
trans^(n-1)[i][j]
```

表示以字母 `i` 开头、字母 `j` 结尾的合法字符串数量。

由于首尾字母可以任意选择，最终答案就是矩阵 `trans^(n-1)` 中所有元素之和。

当 `n=1` 时，矩阵指数为 `0`，结果是单位矩阵，所有元素之和为 `26`，正好表示 26 个单字符字符串。

由于 `n` 最大为 `10^15`，使用矩阵快速幂计算。

## 复杂度分析

矩阵大小固定为 `26×26`。

- 时间复杂度：`O(26³ log n)`
- 空间复杂度：`O(26²)`

## code

```C++
#include <bits/stdc++.h>
using namespace std;

using int64=long long;

const int SIZE=26;
const int64 MOD=1000000007;

struct Matrix{
    int64 value[SIZE][SIZE];

    Matrix(){
        memset(value,0,sizeof(value));
    }
};

Matrix multiply(const Matrix& a,const Matrix& b){
    Matrix result;

    for(int i=0;i<SIZE;i++){
        for(int k=0;k<SIZE;k++){
            if(a.value[i][k]==0){
                continue;
            }

            for(int j=0;j<SIZE;j++){
                result.value[i][j]=(
                    result.value[i][j]
                    +a.value[i][k]*b.value[k][j]
                )%MOD;
            }
        }
    }

    return result;
}

Matrix quick_power(Matrix base,long long exponent){
    Matrix result;

    for(int i=0;i<SIZE;i++){
        result.value[i][i]=1;
    }

    while(exponent>0){
        if(exponent&1){
            result=multiply(result,base);
        }

        base=multiply(base,base);
        exponent>>=1;
    }

    return result;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin>>n;

    string s;
    cin>>s;

    Matrix trans;

    for(int i=0;i<SIZE;i++){
        for(int j=0;j<SIZE;j++){
            trans.value[i][j]=1;
        }
    }

    for(int i=0;i+1<(int)s.size();i++){
        int from=s[i]-'a';
        int to=s[i+1]-'a';

        trans.value[from][to]=0;
    }

    Matrix result=quick_power(trans,n-1);

    int64 answer=0;

    for(int i=0;i<SIZE;i++){
        for(int j=0;j<SIZE;j++){
            answer=(answer+result.value[i][j])%MOD;
        }
    }

    cout<<answer<<'\n';

    return 0;
}
```
