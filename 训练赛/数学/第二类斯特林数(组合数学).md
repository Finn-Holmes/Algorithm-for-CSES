## 题目描述

给定三个整数 `n`、`x` 和 `y`。

一场活动有 `n` 位不同的表演者，每位表演者都要被安排到 `x` 个节目之一，允许某些节目没有表演者。

安排完成后，每个有表演者的节目都会获得一个 `1` 到 `y` 之间的整数评分。

如果表演者所在的节目不同，或者某个非空节目的评分不同，则认为两个活动方案不同。

求活动方案总数，并将答案对 `1000000007` 取模。

## 输入

函数接收三个整数：

```text
n, x, y
```

分别表示表演者数量、节目数量和每个非空节目的评分种数。

## 输出

返回活动方案总数对 `1000000007` 取模后的结果。

## 样例输入

```text
n = 1, x = 2, y = 3
```

## 样例输出

```text
6
```

## 数据范围

- 1 <= n <= 1000
- 1 <= x <= 1000
- 1 <= y <= 1000

## 题解

枚举最终有 `i` 个非空节目，其中：

```text
1 <= i <= min(n,x)
```

接下来分别计算表演者分组、选择节目和节目评分的方案数。

### 第二类斯特林数

定义 `S[i][j]` 表示把 `i` 个不同的表演者划分成 `j` 个非空且没有顺序的集合的方案数。

考虑第 `i` 位表演者：

- 单独组成一个新集合，方案数为 `S[i-1][j-1]`；
- 加入已有的 `j` 个集合之一，方案数为 `j × S[i-1][j]`。

因此：

$$
S[i][j]=S[i-1][j-1]+j\cdot S[i-1][j]
$$

初始状态为：

$$
S[0][0]=1
$$

### 计算总方案数

使用第二类斯特林数划分出的 `i` 个集合没有顺序，而实际的节目有编号。

把这 `i` 个集合分配给 `x` 个不同节目，方案数为排列数：

$$
A_x^i=x(x-1)\cdots(x-i+1)
$$

每个非空节目都有 `y` 种评分，`i` 个节目共有：

$$
y^i
$$

种评分方案。

因此，恰好有 `i` 个非空节目时，方案数为：

$$
A_x^i\cdot S[n][i]\cdot y^i
$$

最终答案为：

$$
\sum_{i=1}^{\min(n,x)}A_x^i\cdot S[n][i]\cdot y^i
$$

枚举 `i` 时，可以递推计算排列数和 `y` 的幂：

$$
A_x^i=A_x^{i-1}(x-i+1)
$$

$$
y^i=y^{i-1}\cdot y
$$

## 复杂度分析

预处理第二类斯特林数的时间复杂度为 `O(n × min(n,x))`。

计算答案的时间复杂度为 `O(min(n,x))`。

空间复杂度为 `O(n × min(n,x))`。

## code

```C++
class Solution {
public:
    int numberOfWays(int n, int x, int y) {
        const long long MOD=1000000007;
        int limit=min(n,x);

        vector<vector<long long>> s(
            n+1,vector<long long>(limit+1,0)
        );

        s[0][0]=1;

        for(int i=1;i<=n;i++){
            for(int j=1;j<=min(i,limit);j++){
                s[i][j]=(
                    s[i-1][j-1]+j*s[i-1][j]
                )%MOD;
            }
        }

        long long ans=0;
        long long perm=1;
        long long power_y=1;

        for(int i=1;i<=limit;i++){
            perm=perm*(x-i+1)%MOD;
            power_y=power_y*y%MOD;

            ans=(
                ans+perm*s[n][i]%MOD*power_y
            )%MOD;
        }

        return ans;
    }
};
```
