## 题目描述

给定整数 `n` 和 `k`，判断能否选择恰好 `k` 个形如 `3^m` 的数字，使它们的和等于 `n`，其中 `m` 是非负整数。

换言之，判断是否存在非负整数序列，使得：

$$
n=3^{a_1}+3^{a_2}+\cdots+3^{a_k}
$$

## 输入

第一行包含一个正整数 `T`，表示测试数据数量。

接下来 `T` 行，每行包含两个整数 `n,k`。

## 输出

对于每组数据，如果可以将 `n` 拆成恰好 `k` 个 3 的非负整数次幂之和，输出 `Yes`，否则输出 `No`。

## 样例输入

```text
4
5 3
17 2
163 79
1000000000000000000 1000000000000000000
```

## 样例输出

```text
Yes
No
Yes
Yes
```

## 数据范围

- 对于 30% 的数据：n ≤ 10，k ≤ 5
- 对于另外 30% 的数据：n ≤ 1000，k ≤ 2
- 对于 100% 的数据：1 ≤ k ≤ n ≤ 10^19，1 ≤ T ≤ 10^5

## 题解

将 `n` 转换成三进制。三进制每一位的数字之和 `sum`，就是表示 `n` 最少需要的 3 的幂的数量。

例如：

$$
5=(12)_3=3^1+3^0+3^0
$$

所以 5 最少需要 3 个数。

对于任意 `m > 0`，都有：

$$
3^m=3^{m-1}+3^{m-1}+3^{m-1}
$$

每拆分一次，数字数量会增加 2。最多可以全部拆成 `3^0=1`，此时共有 `n` 个数。

因此可以拆成恰好 `k` 个数，当且仅当：

```text
sum ≤ k ≤ n
```

并且 `k-sum` 是偶数。

## 复杂度分析

每组数据需要计算 `n` 的三进制数位和。

时间复杂度为 `O(log₃n)`，空间复杂度为 `O(1)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

using ull=unsigned long long;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int t;
    cin>>t;

    while(t--){
        ull n,k;
        cin>>n>>k;

        ull sum=0;
        ull tmp=n;

        while(tmp){
            sum+=tmp%3;
            tmp/=3;
        }

        if(k>=sum&&k<=n&&(k-sum)%2==0){
            cout<<"Yes"<<'\n';
        }else{
            cout<<"No"<<'\n';
        }
    }

    return 0;
}
```
