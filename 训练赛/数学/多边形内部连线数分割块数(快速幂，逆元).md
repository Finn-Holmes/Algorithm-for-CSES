## 题目描述

牛牛画了一个有 `n` 个顶点的正多边形，并用线段连接每一对顶点。

求这些线段将多边形内部划分成了多少个区域，答案对 `1000000007` 取模。

保证 `n` 为奇数，因此不会有三条对角线相交于同一个点。

## 输入

输入一行一个奇数 `n`，表示正多边形的顶点数。

## 输出

输出多边形内部的区域数量，对 `1000000007` 取模。

## 样例输入

```text
5
```

## 样例输出

```text
11
```

## 数据范围

3 ≤ n ≤ 100000000000，且 `n` 为奇数。

## 题解

最开始多边形内部只有一个区域。

每加入一条对角线，它会被已有的交点分成若干段，每一段都会新增一个区域。因此最终区域数为：

$$
区域数=1+对角线数量+对角线交点数量
$$

### 对角线数量

任意选择两个顶点可以得到一条线段，共有：

$$
\binom{n}{2}
$$

其中有 `n` 条是多边形的边，所以对角线数量为：

$$
\binom{n}{2}-n=\frac{n(n-3)}{2}
$$

### 交点数量

在凸多边形中，任意选择四个顶点，都可以确定一组在多边形内部相交的对角线。

由于题目保证没有三条对角线交于同一点，因此每组选出的四个顶点对应唯一的交点：

$$
交点数量=\binom{n}{4}=\frac{n(n-1)(n-2)(n-3)}{24}
$$

所以答案为：

$$
ans=1+\frac{n(n-3)}{2}+\frac{n(n-1)(n-2)(n-3)}{24}
$$

由于需要对质数 `1000000007` 取模，除以 `2` 和 `24` 可以通过费马小定理计算它们的乘法逆元：

$$
a^{-1}\equiv a^{MOD-2}\pmod{MOD}
$$

## 复杂度分析

快速幂计算逆元：

- 时间复杂度：O(log MOD)
- 空间复杂度：O(1)

## code

```C++
#include <bits/stdc++.h>
using namespace std;

const int MOD=1e9+7;

long long quick_pow(long long a,long long b){
    long long ans=1;
    while(b){
        if(b&1){
            ans=ans*a%MOD;
        }
        a=a*a%MOD;
        b>>=1;
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin>>n;

    long long inv2=quick_pow(2,MOD-2);
    long long inv24=quick_pow(24,MOD-2);

    long long dui=n%MOD*((n-3)%MOD)%MOD*inv2%MOD;

    long long jiao=n%MOD*((n-1)%MOD)%MOD
                  *((n-2)%MOD)%MOD*((n-3)%MOD)%MOD
                  *inv24%MOD;

    long long ans=(1+dui+jiao)%MOD;

    cout<<ans;
    return 0;
}
```
