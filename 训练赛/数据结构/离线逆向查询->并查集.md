## 题目描述

有一个 `n × m` 的矩形岛屿，每个格子都有一个高度。

当海平面高度为 `t` 时，高度小于等于 `t` 的格子会被淹没，高度大于 `t` 的格子不会被淹没。

两个未被淹没且拥有公共边的格子属于同一个区域。

给出多个海平面高度，求每个海平面下未被淹没的区域数量。

## 输入

第一行输入一个整数 `Z`，表示测试用例数量。

对于每组测试数据：

- 第一行输入两个整数 `n,m`，表示岛屿大小；
- 接下来 `n` 行，每行输入 `m` 个整数，表示每个格子的高度；
- 下一行输入一个整数 `T`，表示询问数量；
- 最后一行输入 `T` 个非递减排列的整数，表示每次询问的海平面高度。

## 输出

对于每组测试数据，输出一行 `T` 个整数，第 `i` 个整数表示对应海平面下未被淹没的区域数量。

## 样例输入

```text
1
4 5
1 2 3 3 1
1 3 2 2 1
2 1 3 4 3
1 2 2 2 2
5
1 2 3 4 5
```

## 样例输出

```text
2 3 1 0 0
```

## 数据范围

- Z ≤ 20
- 1 ≤ n,m ≤ 1000
- 格子高度在 1 到 1000000000 之间
- 1 ≤ T ≤ 100000
- 海平面高度在 0 到 1000000000 之间
- 询问按照非递减顺序给出

## 题解

海平面逐渐上升时，格子会不断被删除，而并查集不方便维护删除操作。

因此可以倒序处理询问，将海平面看作逐渐下降。随着海平面下降，格子会不断浮出水面，这样就变成了向并查集中添加节点。

先将所有格子按照高度从大到小排序，再将询问从后向前处理。

对于当前海平面 `water`，所有满足下面条件的格子都应该被激活：

$$
height\gt water
$$

注意这里必须是严格大于，因为高度小于等于海平面的格子都会被淹没。

每激活一个格子：

1. 这个格子单独形成一个新区域，区域数量加一；
2. 检查它上下左右的四个相邻格子；
3. 如果相邻格子已经激活，就使用并查集合并；
4. 每成功合并两个不同区域，区域数量减一。

代码中使用 `fa[id] == -1` 表示这个格子还没有被激活。

由于询问本身按照非递减顺序给出，所以直接从最后一个询问向前处理即可。

## 复杂度分析

设格子总数为 `N=n×m`。

- 对格子排序的时间复杂度：O(N log N)
- 并查集处理的时间复杂度：O(N α(N))
- 总时间复杂度：O(N log N)
- 空间复杂度：O(N)

## code

```C++
#include <bits/stdc++.h>
using namespace std;

vector<int> fa;
vector<int> sz;

int n,m;

int find(int x){
    if(fa[x]==x){
        return x;
    }
    return fa[x]=find(fa[x]);
}

bool unite(int x,int y){
    x=find(x);
    y=find(y);

    if(x==y){
        return false;
    }

    if(sz[x]<sz[y]){
        swap(x,y);
    }

    fa[y]=x;
    sz[x]+=sz[y];

    return true;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin>>T;

    while(T--){
        cin>>n>>m;

        vector<pair<int,int>> cell;
        cell.reserve(n*m);

        for(int i=0;i<n;i++){
            for(int j=0;j<m;j++){
                int height;
                cin>>height;

                int id=i*m+j;
                cell.push_back({height,id});
            }
        }

        sort(cell.begin(),cell.end(),
             greater<pair<int,int>>());

        int q;
        cin>>q;

        vector<int> query(q);
        for(int i=0;i<q;i++){
            cin>>query[i];
        }

        vector<int> ans(q);

        fa.assign(n*m,-1);
        sz.assign(n*m,1);

        int pos=0;
        int regions_num=0;

        int dx[4]={0,1,0,-1};
        int dy[4]={1,0,-1,0};

        for(int u=q-1;u>=0;u--){
            int water=query[u];

            while(pos<n*m&&cell[pos].first>water){
                int id=cell[pos].second;
                int x=id/m;
                int y=id%m;

                fa[id]=id;
                sz[id]=1;
                regions_num++;

                for(int d=0;d<4;d++){
                    int xx=x+dx[d];
                    int yy=y+dy[d];

                    if(xx<0||xx>=n||yy<0||yy>=m){
                        continue;
                    }

                    int next=xx*m+yy;

                    if(fa[next]==-1){
                        continue;
                    }

                    if(unite(id,next)){
                        regions_num--;
                    }
                }

                pos++;
            }

            ans[u]=regions_num;
        }

        for(int i=0;i<q;i++){
            if(i>0){
                cout<<' ';
            }
            cout<<ans[i];
        }

        cout<<'\n';
    }

    return 0;
}
```
