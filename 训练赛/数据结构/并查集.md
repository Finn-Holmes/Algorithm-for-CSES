## 题目描述

在一个大小为 `1000 × 1000` 的正方形场地中，有 `n` 个对手。

每个对手的位置为 `(x,y)`，攻击范围为以该位置为圆心、`r` 为半径的圆形区域。

你需要从场地左边界进入，从右边界离开，并且不能经过任何对手的攻击范围。

如果存在多组可行的入口和出口，选择尽可能靠北的位置。

## 输入

第一行输入一个整数 `n`，表示对手数量。

接下来 `n` 行，每行输入三个实数 `x,y,r`，表示一个对手的位置和攻击半径。

## 输出

如果无法从左边界到达右边界，输出：

```text
IMPOSSIBLE
```

否则输出四个实数，依次表示入口和出口的坐标，保留两位小数。

## 样例输入

```text
3
500 500 499
0 0 999
1000 1000 200
```

## 样例输出

```text
0.00 1000.00 1000.00 800.00
```

## 数据范围

n ≤ 1000。

## 题解

将每个对手的攻击范围看成一个圆。

如果两个圆相交或相切，那么不能从它们之间穿过，可以认为这两个圆属于同一个障碍物连通块。

两个圆相交或相切的条件为：

$$
(x_i-x_j)^2+(y_i-y_j)^2\le(r_i+r_j)^2
$$

使用并查集维护这些圆的连通关系，同时建立两个虚拟节点：

- `top` 表示场地上边界；
- `bottom` 表示场地下边界。

如果一个圆满足：

$$
y_i+r_i\ge1000
$$

则将它与 `top` 合并。

如果一个圆满足：

$$
y_i-r_i\le0
$$

则将它与 `bottom` 合并。

如果最终 `top` 和 `bottom` 连通，说明这些圆形成了一堵从上边界连接到下边界的墙，无法从左侧到达右侧。

否则，可以从所有与上边界连通的圆的下方通过。

入口和出口初始都选择最北端的 `y=1000`。然后枚举所有与 `top` 连通的圆，计算它们在左右边界上的最低交点。

对于圆心为 `(x,y)`、半径为 `r` 的圆，它与左边界的最低交点为：

$$
y-\sqrt{r^2-x^2}
$$

它与右边界的最低交点为：

$$
y-\sqrt{r^2-(1000-x)^2}
$$

分别取所有交点的最小值，即为能够安全进入和离开的最北位置。

## 复杂度分析

枚举所有圆对判断是否相交：

- 时间复杂度：O(n²)
- 空间复杂度：O(n)

## code

```C++
#include <bits/stdc++.h>
using namespace std;

vector<int> fa;

void init(int n){
    fa.resize(n);
    for(int i=0;i<n;i++){
        fa[i]=i;
    }
}

int find(int x){
    if(fa[x]==x){
        return x;
    }
    return fa[x]=find(fa[x]);
}

void unite(int x,int y){
    x=find(x);
    y=find(y);

    if(x!=y){
        fa[x]=y;
    }
}

struct circle{
    double x,y,r;
};

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin>>n;

    vector<circle> a(n);

    int top=n;
    int bottom=n+1;

    init(n+2);

    for(int i=0;i<n;i++){
        cin>>a[i].x>>a[i].y>>a[i].r;

        if(a[i].y+a[i].r>=1000){
            unite(i,top);
        }

        if(a[i].y-a[i].r<=0){
            unite(i,bottom);
        }
    }

    for(int i=0;i<n;i++){
        for(int j=i+1;j<n;j++){
            double dx=a[i].x-a[j].x;
            double dy=a[i].y-a[j].y;
            double sum_r=a[i].r+a[j].r;

            if(dx*dx+dy*dy<=sum_r*sum_r){
                unite(i,j);
            }
        }
    }

    if(find(top)==find(bottom)){
        cout<<"IMPOSSIBLE\n";
        return 0;
    }

    double left_y=1000;
    double right_y=1000;

    for(int i=0;i<n;i++){
        if(find(i)!=find(top)){
            continue;
        }

        if(a[i].x-a[i].r<=0){
            double value=a[i].r*a[i].r-a[i].x*a[i].x;
            value=max(0.0,value);

            double h=a[i].y-sqrt(value);
            left_y=min(left_y,h);
        }

        if(a[i].x+a[i].r>=1000){
            double distance=1000-a[i].x;
            double value=a[i].r*a[i].r-distance*distance;
            value=max(0.0,value);

            double h=a[i].y-sqrt(value);
            right_y=min(right_y,h);
        }
    }

    cout<<fixed<<setprecision(2);
    cout<<0.0<<" "<<left_y<<" "
        <<1000.0<<" "<<right_y;

    return 0;
}
```
