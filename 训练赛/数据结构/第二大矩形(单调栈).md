## 题目描述

给定一个大小为 `N × M` 的 01 矩阵，请求出其中面积第二大的全 `1` 矩形。

一个矩形可以用四个整数 `x1,y1,x2,y2` 表示，其中：

- `1 ≤ x1 ≤ x2 ≤ N`
- `1 ≤ y1 ≤ y2 ≤ M`

如果矩形覆盖的所有格子都是 `1`，那么它就是一个合法矩形。

只要两个矩形覆盖的格子不完全相同，就认为它们是不同的矩形。因此，两个不同矩形的面积可以相同。

如果合法矩形少于两个，输出 `0`。

## 输入

第一行包含两个整数 `N,M`，表示矩阵的行数和列数。

接下来 `N` 行，每行包含一个长度为 `M` 的 01 字符串，表示矩阵。

## 输出

输出一个整数，表示面积第二大的全 `1` 矩形的面积。

如果合法矩形少于两个，输出 `0`。

## 样例输入

```text
1 2
01
```

## 样例输出

```text
0
```

## 数据范围

- 1 ≤ N,M ≤ 1000
- N × M ≥ 2
- 矩阵中的字符只包含 `0` 和 `1`

## 题解

将每一行作为矩形的下边界。

用 `height[j]` 表示当前列 `j` 从当前行开始向上连续 `1` 的数量：

- 当前格子是 `1`，则 `height[j]++`；
- 当前格子是 `0`，则 `height[j]=0`。

这样，每处理一行，就会得到一个柱状图，问题转化为在柱状图中寻找矩形。

### 单调栈计算矩形

维护一个柱子高度单调递增的栈。

当遇到高度不大于栈顶柱子的柱子时，弹出栈顶位置 `t`。此时：

- `height[t]` 是矩形高度；
- 当前下标 `j` 是右侧第一个高度更小的位置；
- 弹栈后的栈顶 `left` 是左侧第一个高度更小的位置。

因此矩形宽度为：

$$
width=j-left-1
$$

矩形面积为：

$$
area=height[t]\times width
$$

在每行末尾添加一个高度为 `-1` 的哨兵，使栈中剩余柱子全部弹出。

### 维护第二大矩形

用 `maxnum` 记录当前最大矩形面积，用 `ans` 记录第二大矩形面积。

如果当前矩形面积 `area` 不超过 `maxnum`，那么它本身就是第二大矩形的候选：

```C++
ans=max(ans,area);
```

如果当前矩形面积大于 `maxnum`，原来的最大矩形会成为第二大矩形的候选。

除此之外，还要考虑将当前最大矩形缩小得到的矩形：

- 去掉一行，面积为：

$$
(height[t]-1)\times width
$$

- 去掉一列，面积为：

$$
height[t]\times(width-1)
$$

因此更新：

```C++
ans=max({
    ans,
    maxnum,
    (height[t]-1)*width,
    height[t]*(width-1)
});
```

然后令 `maxnum=area`。

当两个不同矩形的面积相同，并且都等于最大面积时，第二大矩形的面积同样等于最大面积。代码中的 `area<=maxnum` 可以正确处理这种情况。

## 复杂度分析

每个位置在每一行中最多入栈和出栈一次。

时间复杂度为 `O(NM)`。

空间复杂度为 `O(NM)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n,m;
    cin>>n>>m;
    vector<vector<int>> grid(n+1,vector<int>(m+1));
    for(int i=1;i<=n;i++){
        string s;
        cin>>s;
        for(int j=0;j<m;j++){
            grid[i][j+1]=s[j]-'0';
        }
    }
    vector<int> height(m+2,0);
    height[m+1]=-1;
    int ans=0;
    int maxnum=0;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            if(grid[i][j]==0){
                height[j]=0;
            }else{
                height[j]++;
            }
        }
        stack<int> st;
        st.push(0);
        for(int j=1;j<=m+1;j++){
            while(st.size()>1&&height[j]<=height[st.top()]){
                int t=st.top();
                st.pop();
                int left=st.top();
                int ss=height[t]*(j-left-1);
                if(ss<=maxnum){
                    ans=max(ans,ss);
                }else{
                    ans=max({
                        ans,
                        maxnum,
                        (height[t]-1)*(j-left-1),
                        height[t]*(j-left-2)
                    });
                    maxnum=ss;
                }
            }
            st.push(j);
        }
    }
    cout<<ans;
    return 0;
}
```
