## 题目描述

一种商品需要依次经过 `1,2,...,N` 共 `N` 道工序才能制造完成。

对于第 `i` 道工序，可以购买任意数量的两种机器：

- S 机器：每台可以处理 `Ai` 个产品，价格为 `Pi`；
- T 机器：每台可以处理 `Bi` 个产品，价格为 `Qi`。

设第 `i` 道工序的处理量为 `Wi`，整条流水线的处理能力为所有工序处理量的最小值。

现在总预算为 `X`，求流水线能够达到的最大处理能力。

## 输入

第一行输入两个整数 `N,X`，分别表示工序数量和总预算。

接下来 `N` 行，每行输入四个整数：

```text
Ai Pi Bi Qi
```

表示第 `i` 道工序两种机器的处理量和价格。

## 输出

输出一个整数，表示预算范围内能够达到的最大流水线处理能力。

## 样例输入

```text
3 22
2 5 3 6
1 1 3 3
1 3 2 4
```

## 样例输出

```text
4
```

## 数据范围

- 1 <= N <= 100
- 1 <= Ai, Bi <= 100
- 1 <= Pi, Qi, X <= 10000000
- 所有输入均为整数

## 题解

### 二分答案

假设希望流水线的处理能力至少为 `mid`，那么每一道工序的处理量都必须至少为 `mid`。

如果处理能力 `mid` 可以在预算内实现，那么所有小于 `mid` 的处理能力也一定可以实现，因此答案具有单调性，可以使用二分查找。

因为每台机器价格至少为 `1`，处理量最多为 `100`，所以预算 `X` 最多能够得到 `100X` 的处理量，二分范围可以设为 `[0,100X]`。

### 计算一道工序的最小费用

对于某一道工序，假设购买 `s` 台 S 机器和 `t` 台 T 机器，需要满足：

$$
sA_i+tB_i\ge mid
$$

花费为：

$$
sP_i+tQ_i
$$

`Bi` 台 S 机器和 `Ai` 台 T 机器的处理量相同，都是：

$$
A_iB_i
$$

因此可以用价格更低的一组替换价格更高的一组，且处理量不会改变。

所以一定存在一个最优方案满足：

- S 机器数量小于 `Bi`；
- 或者 T 机器数量小于 `Ai`。

于是分别枚举：

- S 机器数量 `s=0,1,...,Bi-1`，计算至少需要多少台 T；
- T 机器数量 `t=0,1,...,Ai-1`，计算至少需要多少台 S。

固定 S 机器数量 `s` 后，至少需要的 T 机器数量为：

$$
t=\left\lceil\frac{\max(0,mid-sA_i)}{B_i}\right\rceil
$$

对每一道工序求出最小费用，然后将所有工序的费用相加。如果总费用不超过 `X`，说明处理能力 `mid` 可以实现。

## 复杂度分析

每次判断需要对每一道工序枚举至多 `Ai+Bi` 种情况。

时间复杂度为 `O(N × (Ai+Bi) × log(100X))`。

空间复杂度为 `O(N)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

struct op{
    long long num,cost;
};

int main(){
    long long n,x;
    cin>>n>>x;

    vector<op> a(n),b(n);

    for(int i=0;i<n;i++){
        cin>>a[i].num>>a[i].cost;
        cin>>b[i].num>>b[i].cost;
    }

    long long left=0,right=100*x;

    while(left<=right){
        long long mid=(left+right)/2;
        long long money=0;
        bool is=true;

        for(int i=0;i<n;i++){
            long long ans=LLONG_MAX;

            for(long long s=0;s<b[i].num;s++){
                long long t;

                if(mid<=s*a[i].num){
                    t=0;
                }else{
                    t=(mid-s*a[i].num+b[i].num-1)/b[i].num;
                }

                ans=min(ans,s*a[i].cost+t*b[i].cost);
            }

            for(long long s=0;s<a[i].num;s++){
                long long t;

                if(mid<=s*b[i].num){
                    t=0;
                }else{
                    t=(mid-s*b[i].num+a[i].num-1)/a[i].num;
                }

                ans=min(ans,s*b[i].cost+t*a[i].cost);
            }

            money+=ans;

            if(money>x){
                is=false;
                break;
            }
        }

        if(is){
            left=mid+1;
        }else{
            right=mid-1;
        }
    }

    cout<<right;
    return 0;
}
```
