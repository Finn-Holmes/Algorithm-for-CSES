## 题目描述

给定两个非负整数 `x` 和 `y`，计算 \(x^y\) 的十进制表示。

由于结果可能非常大，只保留结果的后 `N` 位。本模板中：

```cpp
const int N=500;
```

即只保存结果的最后 500 位。

## 题解

### 高精度存储

使用长度为 `N` 的数组存储一个大整数，每个位置保存一个十进制数位，并且低位在前。

例如：

```text
12345
```

在数组中存储为：

```text
[5,4,3,2,1,0,0,...]
```

因此数组的第 `i` 个位置表示十进制下的 \(10^i\) 位。

底数 `x` 可以通过不断取模拆分：

```cpp
while(x){
    a[i++]=x%10;
    x/=10;
}
```

### 高精度乘法

设两个高精度数分别为 `a` 和 `b`。

根据竖式乘法，`a[i]` 与 `b[j]` 的乘积会对结果的第 `i+j` 位产生贡献：

```cpp
t[i+j]+=a[i]*b[j];
```

每次累加后处理进位：

```cpp
t[i+j+1]+=t[i+j]/10;
t[i+j]%=10;
```

因为题目只需要结果的后 `N` 位，所以计算完成后将数组截断：

```cpp
t.resize(N);
```

截断是正确的，因为高于第 `N-1` 位的数字不会产生向低位的进位。整个计算本质上相当于：

$$
a\times b\bmod 10^N
$$

### 快速幂

普通地连续乘 `y` 次需要 `O(y)` 次高精度乘法。

使用二进制快速幂：

- 如果 `y` 的当前最低位为 1，将当前底数乘入答案；
- 每轮将底数平方；
- 将 `y` 右移一位。

转移过程为：

```cpp
while(y){
    if(y&1){
        res=mul(res,a);
    }

    a=mul(a,a);
    y>>=1;
}
```

这样只需要进行 `O(log y)` 次高精度乘法。

需要注意，每次调用 `quick_pow` 前必须清空全局数组，避免上一次计算的数位残留：

```cpp
fill(a.begin(),a.end(),0);
fill(res.begin(),res.end(),0);
```

## 复杂度分析

一次高精度乘法的时间复杂度为 `O(N^2)`。

快速幂执行 `O(log y)` 轮，因此总时间复杂度为：

```text
O(N^2 log y)
```

空间复杂度为：

```text
O(N)
```

## code

```C++
#include <bits/stdc++.h>
using namespace std;

const int N=500;

// 数字低位在前，只保存结果的后N位
vector<int> a(N),res(N);

vector<int> mul(vector<int>& a,vector<int>& b){
    vector<int> t(2*N);

    for(int i=0;i<N;i++){
        for(int j=0;j<N;j++){
            t[i+j]+=a[i]*b[j];
            t[i+j+1]+=t[i+j]/10;
            t[i+j]%=10;
        }
    }

    // 只保留乘积的后N位
    t.resize(N);

    return t;
}

void quick_pow(long long x,long long y){
    fill(a.begin(),a.end(),0);
    fill(res.begin(),res.end(),0);

    // 任何数的0次幂为1
    res[0]=1;

    // 将底数拆成十进制数位
    int i=0;

    while(x){
        a[i++]=x%10;
        x/=10;
    }

    // 高精度二进制快速幂
    while(y){
        if(y&1){
            res=mul(res,a);
        }

        a=mul(a,a);
        y>>=1;
    }
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    return 0;
}
```

调用：

```cpp
quick_pow(x,y);
```

之后，`res[0...N-1]` 中保存了 \(x^y\) 的后 `N` 位，且低位在前。

如果只输出有效数字，可以从最高位开始跳过前导零：

```C++
int index=N-1;

while(index>0&&res[index]==0){
    index--;
}

for(int i=index;i>=0;i--){
    cout<<res[i];
}
```

如果题目要求固定输出后 `N` 位，不足时在前面补零，则直接输出全部数位：

```C++
for(int i=N-1;i>=0;i--){
    cout<<res[i];
}
```
