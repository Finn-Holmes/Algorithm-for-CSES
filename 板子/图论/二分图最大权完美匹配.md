# KM 算法求二分图最大权完美匹配

## 模板用途

求左右两侧节点数相同的带权二分图中的最大权完美匹配。

## 核心思路

- 维护左右节点顶标，使任意边满足 `la[x]+lb[y]≥w[x][y]`。
- 只在等式成立的相等子图中寻找增广路。
- 无法增广时，根据最小松弛量调整顶标，直到出现新的可用边。

## 复杂度分析

时间复杂度为 `O(n^3)`，空间复杂度为 `O(n^2)`。

## 使用提示

这是学习模板，使用时需要根据具体题目补充节点数、边数、数组范围、输入输出以及必要的初始化。模板文件中若包含多个相近算法，应按对应小节选择其中一种实现，而不是把多个独立程序同时编译。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
const int N=520;
const int MX=1e15;
int match[N],va[N],vb[N];
long long la[N],lb[N];
long long w[N][N],d[N];
int n,m;
bool dfs(int x){
	va[x]=1;
	for(int y=1;y<=n;y++){
		if(!vb[y]){
			if(la[x]+lb[y]-w[x][y]==0){
				vb[y]=1;
				if(match[y]==0||dfs(match[y])){
					match[y]=x;
					return true;
				}
			}else{
				d[y]=min(d[y],la[x]+lb[y]-w[x][y]);
			}
		}
	}
	return false;
}
long long KM(){
	for(int i=1;i<=n;i++){
		la[i]=-MX;
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=n;j++){
			la[i]=max(la[i],w[i][j]);
		}
	}
	for(int i=1;i<=n;i++){
		lb[i]=0;
	}
	for(int i=1;i<=n;i++){
		while(true){
			fill(va+1,va+n+1,0);
			fill(vb+1,vb+n+1,0);
			fill(d+1,d+n+1,MX);
			if(dfs(i)==true) break;
			long long dr=INT_MAX;
			for(int j=1;j<=n;j++){
				if(vb[j]==0){
					dr=min(dr,d[j]);
				}
			} 
			for(int j=1;j<=n;j++){
				if(va[j]) la[j]-=dr;
				if(vb[j]) lb[j]+=dr;
			}
		} 
	}
	long long res=0;
	for(int i=1;i<=n;i++){
		res+=w[match[i]][i];
	}
	return res;
}
int main(){
	ios::sync_with_stdio(0);
	cin.tie(0);
	cout.tie(0);
	int a,b,x;
	cin>>n>>m;
	for(int i=1;i<=m;i++){
		cin>>a>>b>>x;
		w[a][b]=x;
	}
	for(int i=1;i<=n;i++){
		for(int j=1;j<=n;j++){
			if(w[i][j]==0){
				w[i][j]=-MX;
			}
		}
	}
	cout<<KM()<<'\n';
	for(int i=1;i<=n;i++){
		cout<<match[i]<<" ";
	}
}
```
