# 二分图判定（染色法）

## 模板用途

判断一个无向图能否被划分为两个集合，使每条边的两个端点属于不同集合。

## 核心思路

- 对每个尚未染色的连通块进行 DFS。
- 当前节点染成颜色 `c`，相邻节点必须染成 `3-c`。
- 若发现一条边两端颜色相同，则图不是二分图。

## 复杂度分析

时间复杂度为 `O(n+m)`，空间复杂度为 `O(n+m)`。

## 使用提示

这是学习模板，使用时需要根据具体题目补充节点数、边数、数组范围、输入输出以及必要的初始化。模板文件中若包含多个相近算法，应按对应小节选择其中一种实现，而不是把多个独立程序同时编译。

#include <bits/stdc++.h>
using namespace std;
struct edge{
	int v,ne;
}e[M];//˫��ߣ���˫�� 
int idx,h[M],colors[M];
void add(int a,int b){
	e[++idx]={b,h[a]};
	h[a]=idx;
}
bool dfs(int u,int c){
	colors[u]=c;
	for(int i=h[u];i;i=e[i].ne){
		int v=e[i].v;
		if(colors[v]==0){
			if(dfs(v,3-c)==false) return false;
		}else if(colors[v]==c) return false;
	}
	return true;
}
int main(){

		}
	} 
	return true;
}
