# 匈牙利算法求二分图最大匹配

## 模板用途

求二分图中最多能够选出多少条互不共享端点的边。

## 核心思路

- 依次尝试为左部每个节点寻找匹配。
- 若目标右部节点未匹配，则直接匹配；否则尝试让它当前匹配的左部节点寻找其他位置。
- 每轮使用 `vis` 防止同一个右部节点被重复搜索。

## 复杂度分析

时间复杂度为 `O(VE)`，空间复杂度为 `O(V+E)`。

## 使用提示

这是学习模板，使用时需要根据具体题目补充节点数、边数、数组范围、输入输出以及必要的初始化。模板文件中若包含多个相近算法，应按对应小节选择其中一种实现，而不是把多个独立程序同时编译。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
const int M=50010,N=520;
struct edge{
	int v,ne;
}e[M];
int idx,h[N],match[N];
bool vis[N];
void add(int a,int b){
	e[++idx]={b,h[a]};
	h[a]=idx;
}
bool dfs(int u){
	for(int i=h[u];i;i=e[i].ne){
		int v=e[i].v;
		if(vis[v]==true) continue;
		vis[v]=true;
		if(match[v]==0||dfs(match[v])==true){
			match[v]=u;
			return true;
		}
	}
	return false;
}
int main(){
	ios::sync_with_stdio(0);
	cin.tie(0);
	cout.tie(0);
	int n,m,r,a,b;
	cin>>n>>m>>r;
	for(int i=1;i<=r;i++){
		cin>>a>>b;
		add(a,b);
	}
	int ans=0;
	for(int i=1;i<=n;i++){
		memset(vis,false,sizeof(vis));
		if(dfs(i)==true){
			ans++;
		}
	}
	cout<<ans;
	return 0;
}
```
