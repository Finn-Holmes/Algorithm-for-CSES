# 矩阵行列置换与二分图完美匹配

## 模板用途

判断 01 矩阵能否通过行列交换，使主对角线全部为 `1`。

## 核心思路

- 把每一行看作左部节点，每一列看作右部节点；矩阵中的 `1` 表示存在一条边。
- 主对角线全部为 `1` 等价于每一行都能匹配一个不同的列。
- 使用匈牙利算法求最大匹配，匹配数等于 `n` 时存在方案。

## 复杂度分析

时间复杂度为 `O(n^3)`，空间复杂度为 `O(n^2)`。

## 使用提示

这是学习模板，使用时需要根据具体题目补充节点数、边数、数组范围、输入输出以及必要的初始化。模板文件中若包含多个相近算法，应按对应小节选择其中一种实现，而不是把多个独立程序同时编译。

## code

```C++
#include<bits/stdc++.h>
using namespace std;
const int N=1005;
vector<int>graph[N];
int match[N];
int vis[N];
int now;
bool dfs(int u){
    for(int v:graph[u]){
        if(vis[v]==now)continue;
        vis[v]=now;
        if(match[v]==-1||dfs(match[v])){
            match[v]=u;
            return true;
        }
    }
    return false;
}
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t,n;
    cin>>t;
    while(t--){
    	cin>>n;
        for(int i=0;i<n;i++)graph[i].clear();
        memset(match,-1,sizeof(match));
        memset(vis,0,sizeof(vis));
        now=0;
        for(int i=0;i<n;i++){
            for(int j=0;j<n;j++){
                int x;
                cin>>x;
                if(x==1)graph[i].push_back(j);
            }
        }
        int cnt=0;
        for(int i=0;i<n;i++){
            now++;
            if(dfs(i))cnt++;
        }
        if(cnt==n)cout<<"Yes\n";
        else cout<<"No\n";
    }
    return 0;
}
```
