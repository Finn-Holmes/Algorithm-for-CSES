## 题目描述

给定 `n` 种不同面值的硬币，每种硬币都可以使用任意次。

请计算组成目标金额 `x` 的方案数。硬币的使用顺序不同不算新的方案。

例如，`2+2+5`、`2+5+2` 和 `5+2+2` 都属于同一种方案。

## 输入

第一行包含两个整数 `n,x`，分别表示硬币种类数和目标金额。

第二行包含 `n` 个不同的整数 `c1,c2,...,cn`，表示每种硬币的面值。

## 输出

输出组成金额 `x` 的方案数，答案对 `10^9+7` 取模。

## 样例输入

```text
3 9
2 3 5
```

## 样例输出

```text
3
```

## 数据范围

- 1 ≤ n ≤ 100
- 1 ≤ x ≤ 10^6
- 1 ≤ ci ≤ 10^6

## 题解

这是一个完全背包计数问题，但与 Coin Combinations I 不同，本题不考虑硬币的排列顺序。

定义 `dp[j]` 表示组成金额 `j` 的方案数，初始化：

```C++
dp[0]=1;
```

外层枚举硬币 `a[i]`，内层从小到大枚举金额。对于金额 `j`，可以在组成 `j-a[i]` 的方案后加入一枚当前硬币：

$$
dp[j]=dp[j]+dp[j-a[i]]
$$

金额从小到大枚举，使当前硬币可以被重复使用；先枚举硬币，则保证每种硬币组合只被统计一次，不会因为排列顺序不同而重复计算。

## 复杂度分析

时间复杂度为 `O(nx)`，空间复杂度为 `O(x)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

#define MX 1000000007
 
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n,m;
    cin>>n>>m;

    vector<int> a(n);

    for(int i=0;i<n;i++){
        cin>>a[i];
    }
 
    vector<long long> dp(m+1,0);
    dp[0]=1;
 
    for(int i=0;i<n;i++){
        for(int j=a[i];j<=m;j++){
            dp[j]=(dp[j]+dp[j-a[i]])%MX;
        }
    }

    cout<<dp[m]<<'\n';

    return 0;
}
```
