## 题目描述

给定 `n` 种不同面值的硬币，每种硬币都可以使用任意次。

请计算组成目标金额 `x` 的方案数。硬币出现的顺序不同，视为不同方案。

例如，`2+2+5`、`2+5+2` 和 `5+2+2` 是三种不同方案。

## 输入

第一行包含两个整数 `n,x`，分别表示硬币种类数和目标金额。

第二行包含 `n` 个不同的整数 `c1,c2,...,cn`，表示每种硬币的面值。

## 输出

输出组成金额 `x` 的方案数，答案对 `10^9+7` 取模。

## 样例输入

```text
3 9
2 3 5
```

## 样例输出

```text
8
```

## 数据范围

- 1 ≤ n ≤ 100
- 1 ≤ x ≤ 10^6
- 1 ≤ ci ≤ 10^6

## 题解

这是一个完全背包计数问题，并且硬币顺序不同算作不同方案。

定义 `dp[i]` 表示组成金额 `i` 的有序方案数，初始化：

```C++
dp[0]=1;
```

计算金额 `i` 时，枚举最后使用的硬币 `a[j]`。去掉这枚硬币后，前面的硬币需要组成金额 `i-a[j]`，因此：

$$
dp[i]=\sum dp[i-a[j]]
$$

外层枚举金额、内层枚举硬币，可以让不同的硬币使用顺序被分别统计。

代码先对硬币排序，当 `a[j]>i` 时，后面的硬币也无法使用，可以直接结束枚举。

## 复杂度分析

时间复杂度为 `O(nx+n log n)`，空间复杂度为 `O(x)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

#define MX 1000000007

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n,m;
    cin>>n>>m;

    vector<long long> a(n);

    for(int i=0;i<n;i++){
        cin>>a[i];
    }

    sort(a.begin(),a.end());

    vector<int> dp(m+1,0);
    dp[0]=1;

    for(int i=1;i<=m;i++){
        for(int j=0;j<n;j++){
            if(a[j]<=i){
                dp[i]+=dp[i-a[j]];
                dp[i]=dp[i]%MX;
            }else{
                break;
            }
        }
    }

    cout<<dp[m]%MX;

    return 0;
}
```
