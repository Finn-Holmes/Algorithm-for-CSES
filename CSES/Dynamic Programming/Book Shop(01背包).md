## 题目描述

书店中有 `n` 本不同的书，每本书都有对应的价格和页数。

你可以购买其中一些书，要求总价格不超过 `x`，并且每本书最多购买一次。

求最多能够买到多少页。

## 输入

第一行包含两个整数 `n,x`，分别表示书的数量和最大预算。

第二行包含 `n` 个整数 `h1,h2,...,hn`，表示每本书的价格。

第三行包含 `n` 个整数 `s1,s2,...,sn`，表示每本书的页数。

## 输出

输出一个整数，表示在预算不超过 `x` 的情况下，最多能够买到的页数。

## 样例输入

```text
4 10
4 8 5 3
5 12 8 1
```

## 样例输出

```text
13
```

## 数据范围

- 1 ≤ n ≤ 1000
- 1 ≤ x ≤ 10^5
- 1 ≤ hi ≤ 1000
- 1 ≤ si ≤ 1000

## 题解

每本书只有“购买”和“不购买”两种选择，并且最多购买一次，因此这是一个 01 背包问题。

定义 `dp[j]` 表示预算不超过 `j` 时，最多能够买到的页数。

对于第 `i` 本书，如果购买它，需要花费 `h[i]`，并获得 `s[i]` 页，因此转移为：

$$
dp[j]=\max(dp[j],dp[j-h[i]]+s[i])
$$

容量 `j` 必须从大到小枚举，避免当前书在同一轮中被重复使用。

## 复杂度分析

时间复杂度为 `O(nx)`，空间复杂度为 `O(x)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
 
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n,x;
    cin>>n>>x;

    vector<int> h(n);
    vector<int> s(n);

    for(int i=0;i<n;i++){
        cin>>h[i];
    }

    for(int i=0;i<n;i++){
        cin>>s[i];
    }

    vector<int> dp(x+1,0);
    dp[0]=0;

    for(int i=0;i<n;i++){
        for(int j=x;j>=h[i];j--){
            dp[j]=max(dp[j],dp[j-h[i]]+s[i]);
        }
    }

    cout<<dp[x];

    return 0;
}
```
