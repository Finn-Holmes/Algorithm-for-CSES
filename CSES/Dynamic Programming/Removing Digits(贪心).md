## 题目描述

给定一个正整数 `n`。

每次操作可以选择当前数字中的一个数位，并将这个数位从当前数字中减去。

求将 `n` 变成 0 所需的最少操作次数。

## 输入

输入一行一个整数 `n`。

## 输出

输出将 `n` 变成 0 所需的最少操作次数。

## 样例输入

```text
27
```

## 样例输出

```text
5
```

## 数据范围

- 1 ≤ n ≤ 10^6

## 题解

为了用尽可能少的操作把数字变成 0，每次应当减去当前数字中最大的数位。

例如当前数字为 `27`，可以减去 2 或 7。选择 7 后得到 20，比选择 2 后得到 25 更接近 0。

每次取出当前数字的所有数位，找到最大数位并减去，直到数字变为 0，操作次数就是答案。

样例的变化过程为：

```text
27 → 20 → 18 → 10 → 9 → 0
```

## 复杂度分析

设最终操作次数为 `ans`，数字位数为 `d`。

时间复杂度为 `O(ans·d log d)`，空间复杂度为 `O(d)`。

由于本题中 `d≤7`，每次操作的开销很小。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
 
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n,ans=0;
    cin>>n;

    while(n>0){
        vector<int> a;
        int m=n;

        while(m>0){
            a.push_back(m%10);
            m/=10;
        }

        sort(a.begin(),a.end(),greater<int>());

        n-=a[0];
        ans++;
    }

    cout<<ans;

    return 0;
}
```
