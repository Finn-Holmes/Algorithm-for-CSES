## 题目描述

给定 `n` 种不同面值的硬币，每种硬币都可以使用任意次。

请使用这些硬币组成金额 `x`，并求所需硬币数量的最小值。

如果无法组成金额 `x`，输出 `-1`。

## 输入

第一行包含两个整数 `n,x`，分别表示硬币种类数和目标金额。

第二行包含 `n` 个不同的整数 `c1,c2,...,cn`，表示每种硬币的面值。

## 输出

输出组成金额 `x` 所需的最少硬币数量。

如果无法组成，输出 `-1`。

## 样例输入

```text
3 11
1 5 7
```

## 样例输出

```text
3
```

## 数据范围

- 1 ≤ n ≤ 100
- 1 ≤ x ≤ 10^6
- 1 ≤ ci ≤ 10^6

## 题解

定义 `dp[i]` 表示组成金额 `i` 所需的最少硬币数量。

初始化时令 `dp[0]=0`，其他状态设为一个无法达到的大值。对于每种不超过目标金额的硬币，可以直接组成对应金额，因此：

```C++
dp[a[i]]=1;
```

计算 `dp[i]` 时，枚举最后使用的硬币 `a[j]`。如果之前能够组成金额 `i-a[j]`，那么可以再加入一枚硬币得到金额 `i`：

$$
dp[i]=\min(dp[i],dp[i-a[j]]+1)
$$

如果最终 `dp[x]` 仍然是初始的大值，说明无法组成目标金额。

## 复杂度分析

时间复杂度为 `O(nx)`，空间复杂度为 `O(x)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;
 
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int n,m;
    cin>>n>>m;

    vector<int> a(n+1);

    for(int i=1;i<=n;i++){
        cin>>a[i];
    }

    vector<int> dp(m+1,m+1);
    dp[0]=0;

    for(int i=1;i<=n;i++){
        if(a[i]<=m){
            dp[a[i]]=1;
        }
    }

    for(int i=2;i<=m;i++){
        for(int j=1;j<=n;j++){
            if(i-a[j]>=1){
                dp[i]=min(dp[i],dp[i-a[j]]+1);
            }
        }
    }

    if(dp[m]>m){
        cout<<-1;
    }else{
        cout<<dp[m];
    }

    return 0;
}
```
