## 题目描述

给定一个整数 `n`，求通过投掷一次或多次骰子，使所有点数之和等于 `n` 的方案数。

每次投掷骰子可以得到 1 到 6 之间的一个整数，并且投掷顺序不同算作不同方案。

例如，当 `n=3` 时，共有以下 4 种方案：

```text
1+1+1
1+2
2+1
3
```

## 输入

输入一行一个整数 `n`。

## 输出

输出组成 `n` 的方案数，答案对 `10^9+7` 取模。

## 样例输入

```text
3
```

## 样例输出

```text
4
```

## 数据范围

- 1 ≤ n ≤ 10^6

## 题解

定义 `dp[i]` 表示组成数字 `i` 的方案数。

为了方便转移，令：

```C++
dp[0]=1;
```

对于和为 `i` 的方案，最后一次骰子的点数可以是 1 到 6。假设最后一次得到 `j`，那么前面的点数之和应该为 `i-j`。

因此转移方程为：

$$
dp[i]=\sum_{j=1}^{6}dp[i-j]
$$

其中只计算满足 `i-j≥0` 的情况。每次计算后对 `10^9+7` 取模。

## 复杂度分析

每个状态最多枚举 6 种骰子点数。

时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

## code

```C++
#include <bits/stdc++.h>
using namespace std;

#define MX 1000000007

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin>>n;

    vector<long long> dp(n+1,0);
    dp[0]=1;

    for(int i=1;i<=n;i++){
        for(int j=1;j<=6;j++){
            if(i-j>=0){
                dp[i]=(dp[i]+dp[i-j])%MX;
            }
        }
    }

    cout<<dp[n];

    return 0;
}
```
